# Plan 지침 4차(추가) — B 정제판에 "공기감" 더하기 (3차 지침의 보충·일부 대체)

작성: 2026-11-20 (메인 세션). 모델: Sonnet. **`agents/plan-ui-depth-3-element-gems.md`(3차)를 그대로 따르되, 아래로 보충·대체한다.** 안전 규칙·산출물 위치·하니스·측정 방법은 1~3차 그대로.

## 사용자 요청 (2026-11-20, 그대로)
1. *"공기감도 나오게 하면서 구현 가능한 방안을 설계해줘"*
2. *"꼭 유리가 아니어도 돼. 이러한 느낌으로 깔끔한 시안이 마음에 든 것이야."*
→ 사용자가 좋아한 것은 **B의 유리 재질이 아니라 "깔끔한 느낌"**이다. 따라서 **유리(비침·흐림·반투명)는 필수가 아니고**, 3차의 "비침을 포기한다"는 방향이 맞다. 다만 **"공기감"(면이 무겁지 않고 가볍게 떠 있는 느낌, 숨 쉴 틈)은 남겨야 한다.** 복잡한 반투명 설계(저알파 + 큰 블러 + 채도 부스트, 액자 구조 등)는 **하지 않는다**(이번 범위 밖, 결정 항목에 "필요하면 나중에 별도 시안"으로만 적는다).

## 3차 지침에서 바뀌는 것
- 시안은 **B-1 "맑은 유리"와 B-2 "도자기" 2안 그대로**(파일명도 그대로 `ui-depth-BG.css`·`ui-depth-BC.css`)이고, **둘 다에 아래 "공기감 레시피"를 넣는다.** 새 3안(B-3)은 만들지 않는다. 3차의 "B-1 = 유리 질감 단서(윗 하이라이트·안쪽 흰 테두리) 남김 / B-2 = 질감 없는 순수 면"의 차이는 유지한다.
- 3차의 "반투명(알파 < .96) 면 0개·흐림/필터 0개" 규칙은 **기본값으로 유지**한다. 단 B-1에 한해 **"비침 한 스푼" 실험 1회**를 허용한다: 큰 패널 2~3개(레벨 설명판·명예의 전당 패널·일시정지 패널)만 알파 .92~.95, 블러 없음으로 두고 풍경 색이 은은히 스미는지 확대 비교한다. 면이 조금이라도 뿌옇게 보이면 **즉시 버리고**(기본 시안에는 넣지 않는다) 실험 이미지(`ui-depth-haze-spoon.png`)와 "채택하지 않은 이유"만 남긴다.

## 공기감 레시피 (두 안 공통 — "깔끔함"을 해치지 않는 선에서만)
**공기감 = 면이 둔탁하지 않고 가볍게 떠 있으며, 색이 맑고, 윤곽이 또렷하되 무겁지 않은 느낌.** 아래 6가지를 **수치로 정해 적용**하고 값표에 남긴다.
1. **떠 있는 그림자**: 바닥 접촉 작은 그림자 1겹 + **넓고 연한 확산 그림자 1겹**(블러 24~40px, 알파 .10~.18, 색조는 정글의 청록·하늘의 남보라와 어울리게 하나로 통일). 큰 패널일수록 더 넓고 연하게(층 3단계: 바탕 / 떠 있는 면 / 잠깐 뜨는 것). 모두 **블러 > 0, 방향성 있는 하드 그림자 금지**(받침 아님).
2. **위에서 오는 빛**: 면의 위쪽이 더 밝고 아래가 아주 살짝 색조를 띠는 연한 세로 그라데이션(순백 → 연보라/연하늘/연크림), 윗 1px 하이라이트. 모든 요소가 **같은 광원(위)**을 따른다.
3. **링의 강약 차등(가벼움의 핵심)**: 정보 줄·알약·HUD는 **연한 헤어라인**(알파 ≈ .14~.22), **누르는 것**(선택칩·주요/보조 버튼)은 **진한 1px 링**(알파 ≈ .45~.55 또는 면 색 한 단계 진한 색). 모든 것에 같은 진한 테두리를 두르면 무겁고 둔탁해지므로 **차등**한다. 링은 항상 사방이 같다(받침 아님).
4. **좌상단 반사광(큰 패널에만, 1개)**: `radial-gradient(120% 90% at 0% 0%, rgba(255,255,255,.55), transparent 55%)` 계열. 띠·줄무늬 모양(D의 대각선 면 분할)은 쓰지 않는다. 작은 알약·버튼에는 넣지 않는다.
5. **색의 맑음**: 면 색을 회색 섞인 흰색이 아니라 **채도가 살아 있는 연한 색조**(순백 대신 `#fffdf8` 크림, 연보라 `#f4f0ff`, 연하늘 `#f2f9ff`)로 정해 "회색 안개" 인상을 없앤다. 알파로 풍경을 섞지 않는다(불투명 유지).
6. **숨 쉴 틈(레이아웃은 건드리지 않는다)**: 간격·크기는 바꾸지 않는다(레이아웃 이동 0 규칙). 대신 **글자·아이콘 색 대비와 링 강약으로 시각적 여백**을 만든다(정보 줄의 링을 연하게 하면 면 사이가 넓어 보인다).
- **효과 수 제한**: 한 요소에 쓰는 효과는 **면(그라데이션+윗 하이라이트) + 링 + 확산 그림자**까지, **큰 패널에만** 반사광 1개 추가. 그 이상 쌓지 않는다(깔끔함 우선). 흰 바깥 테두리 + 받침 + 드롭 섀도 겹쳐 쌓기 금지.

## 측정·점검 추가
- **공기감 점검표**(시안마다 스크린샷을 보고 예/아니오와 한 줄 근거): ① 면이 무겁지 않고 떠 보이는가(그림자 반경·알파 값 기재) ② 링이 정보 줄은 연하고 누르는 것은 진한가(알파 값) ③ 색이 맑고 회색 안개가 없는가(면 안쪽 색 편차·크롭 확인) ④ 한 화면에서 효과가 깔끔하게 보이는가(그림자 층 수) ⑤ **B 원래와 같은 사람이 만든 것으로 보이는가**.
- 3차의 모든 측정(약점 5개 상쇄 여부 포함)은 그대로.
- **`ui-depth-haze-*` 확대 비교**(B 원래 / B-1 / B-2)에 "공기감"이 보이게 같은 영역을 찍고, B-1의 "비침 한 스푼" 실험은 별도 이미지로 둔다.
