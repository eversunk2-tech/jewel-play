# Plan 지침 M3-CAL — 교육용 "많이" 모드 표 재보정과 "보통" 모드 확인, 문제 수·학습 조건 측정 (spec §27.5·§27.7)

## 역할
너는 **Plan 담당**(Sonnet 서브에이전트)이다. §27 M3의 **수치 보정만** 맡는다. M3-A·M3-B 구현이 끝난 **교육용 `apps/element-gems-edu/game.js`**(미션 엔진 이식 + 문제 양 선택 + pity·guard·상한 6 + 학습 조건)를 **실제 게임 그대로** 돌려서, 교육용 **"많이" 모드의 표**(초보 점수 표, 중수·고수 미션 표)를 정하고 "보통" 모드가 일반용과 어긋나는지 확인하며, 문제 수·학습 조건 수치를 측정한다. 코드·`CONFIG`는 **수정하지 않는다**. 결과는 `apps/element-gems/spec.md` **끝에 새 § 번호로 이어 붙이고**(`cat >> … <<'EOF'`로 한 번에, 기존 § 수정 금지; 마지막 § 번호가 **37**인지 먼저 확인하고 **§38**을 쓴다), 붙여넣기 쉬운 JSON을 scratchpad에 둔다. **직접 계산·측정한 것만** 쓰고 확인 못 한 것은 한계로 적는다.
먼저 `CLAUDE.md`, `docs/STATUS.md` §14, `apps/element-gems/spec.md`의 **§27.4~§27.5**(곡선·표·검증), **§27.7**(교육용 공급·학습 설계·문제 수·시간 모델), §27.13, **§28**(점수 규칙)·§28.7.4(교육용 정답 보너스 ×3), **§31**(초보 점수 표), **§35~§37**(최근 구현·보정 기록), `agents/build-mission-m3a-element-gems-edu.md`·`build-mission-m3b-element-gems-edu.md`(무엇을 만들었는지)를 읽는다. 줄 번호는 참고용이니 제목으로 찾는다.

## 배경
- §27.5의 교육용 "많이" 표는 **§26(보드 구조)·§28(점수 ×3)·§31·§36 이전**의 값이라 어긋난다. M3-B는 `CONFIG.edu.many`에 **임시값**(`easyTargets` = 보통 모드 파생값 = 일반용 초보 표 × 1.2, `missions` = 일반용 §36 표와 같은 수)을 넣어 두었다. 이것을 보정한다.
- 교육용 점수 규칙: 정답 보너스 = 900 × 난이도 배율(초보 720·중수 900·고수 1,170), 연쇄·콤보 배율을 곱하지 않는 일시불. "많이" 모드에서는 레벨당 푼 문제가 6~12개라 초보 점수 레벨의 보너스 비중이 크다(§27.7.4).
- **사용자 결정(유지)**: 교육용 목표 = 일반용 × 1.2는 바꾸지 않는다 — 보통 모드와 초보 1단계의 기본 배율. "많이" 모드 초보의 후반 가산(§27.5.1의 ×1.2 → ×1.8 완만한 상향 표)은 **제안**이므로, 너는 (가) 배율 ×1.2 고정 (나) 필요한 만큼 후반 배율을 올린 표 둘 다를 재고 (나)를 권장안 후보로 낼 수 있다. 어느 쪽이든 1단계는 ×1.2.

## 이번에 정하는 것 (그 밖은 바꾸지 않는다)
1. **"많이" 모드 초보 점수 표** `easyTargets` 10칸(100점 단위, 증가 수열): 교육용 "많이" 기준 플레이어의 클리어율이 **일반용 초보 기준 플레이어 곡선과 ±5%p 안**이 되도록. 일반용 곡선은 **같은 봇·같은 방법으로 먼저 직접 측정**해서 기준으로 삼는다(§35·§31.3 기록 참고: 새 규칙·새 표에서 기준 플레이어 3.0초·스킬 30%·무작위 ≈ 98·97·94·93·92·89·86·74·63·54%).
2. **"많이" 모드 중수·고수 미션 표** `missions.normal/hard` 각 10칸의 **개수·횟수**: 유형 구성(어떤 종류의 부분 미션, 어떤 색)은 일반용 §36과 **같게** 두고 수만 조정(`?`가 매치를 쉽게 해 같은 수면 클리어율이 +10~20%p 오르는 효과와 학습 조건으로 클리어가 늦어지는 효과를 반영). 목표 곡선(기준 플레이어): 중수 D = **95·90·94·84·72·80·66·58·68·38**, 고수 H = **90·82·88·74·60·70·54·46·58·28**, ±5%p. 제약은 M2-CAL(§36)과 같다: 동시 칩 부분 ≤ 2(SEQ ≤ 4), 드문 사건 횟수 1~3, 같은 레벨에서 초보 ≥ 중수 ≥ 고수, 3·6·9단계가 앞 레벨보다 쉬움(≥ +4%p)·5·10단계가 직전보다 어려움. 정수 때문에 ±5%p 밖이 되는 칸은 이유와 대안을 쓴다.
3. **"보통" 모드 확인**(표는 바꾸지 않는다): 교육용 보통(공급 1.6%·max 2·학습 조건 없음·초보 ×1.2·미션 §36)이 일반용과 비교해 기준 플레이어 클리어율이 **±5%p 안**인지. 벗어난 칸은 표로 보고하고 보통 모드 전용 조정안을 **제안으로만** 쓴다(사용자 결정은 "보통 = 일반용과 같은 수").
4. **문제 수·학습 조건**("많이" 모드): 레벨별 **푼 문제 수**(클리어한 판의 평균·하위 10%·최소) — 목표는 §27.7.3(초보 6.4→12, 중수 8→12, 고수 8→11, 평균 12개 이하), **학습 부족 실패**(목표는 채웠는데 문제가 모자라 시간 초과한 판) ≤ 1%, 보드 위 ? 개수(평균·최대, **최대 ≤ 6**, 6개가 되는 판의 비율), 재섞기 판당 평균 ≤ 0.05, 한 판에 문제 팝업이 몰리는 정도(한 행동 최대 3). 기준 정답률 75%, 민감도 40·95%(중수·고수 클리어율이 정답률과 무관해야 하고, 초보 점수는 정답 보너스 때문에 달라진다 — 후반 레벨 영향 크기를 보고). 문제 풀이 시간은 게임 시계가 정지하므로 클리어율에 영향이 없지만, **수업 시간 모델**(문제 1개 20초·30초 가정)로 레벨당 시간도 §27.7.3처럼 갱신.
5. **별 분포**: 교육용 "많이" ★★★ 비율을 일반용과 나란히(§27.7.4 위험 ②: 합산 순위 형평). 완화안이 필요하면 **제안으로만**.
