## 검증 항목
1. **spec §18.7 체크리스트 전체**를 표(항목/결과/근거)로.
2. **기능 회귀 없음(최우선)**: `game.js` md5가 직전(c1a557e4…)과 동일한지 확인. Node 단위 테스트 재통과(2×2·매치·힌트·스테이지·저장 마이그레이션·목표 점수 표). 브라우저에서 시작 → 난이도 선택 → 레벨 선택 → 게임(스왑·매치·연쇄) → 스킬 **6종 모두** 컷인→효과(Build는 어둠 1종만 직접 봄) → 일시정지/나가기/리셋 → 클리어·**실패(TIME UP)** 결과까지. 콘솔 에러·경고 0건, 에셋 404 없음.
3. **보드·보석 가독성**: 6종 보석이 모든 칸 상태(기본/선택/힌트/커서/제거/조준)에서 모양·표정·색으로 식별되는지(흑백 변환 스크린샷 포함), **흰 보석(빛)과 파란 물방울**의 대비, 칸 상태 해제 후 잔상(`::before`) 없음, 보석 이미지 로드 실패(SVG 폴백) 시 새 타일 위에서도 보임.
4. **배경 구성(변경 사항)**: 정글 이미지 + 파스텔 틴트가 시작/게임/레벨 선택/오버레이에서 일관되고, 글자·카드·보드 가독성을 해치지 않는지. 이미지 로드 실패 폴백(하늘 그라디언트만)이 자연스러운지. 가로 모드·데스크톱(1280×800)에서 정글이 너무 어둡거나 칙칙해 보이지 않는지, 컷인 딤(.55) 위에서 풍경 비침이 가독성에 문제 없는지.
5. **로고**: 새 로고(900×605)가 시작 화면·결과·일시정지·낮은 화면(≤700px)·가로 모드에서 잘리거나 레이아웃을 밀지 않는지, 로고 주변 흰 테두리/잔상 없음.
6. **대비**: 렌더된 실제 색으로 텍스트 대비 재측정(≥4.5:1, 큰 글자 ≥3:1). Build의 자동 점검(81개 텍스트)을 독립적으로 재현해 비교. 그라디언트 위 글자(타이머, 목표 바, 버튼), `.timer.low`, 비활성 상태, 레벨 카드 목표 글씨(약 11px)·별 색, 조준·힌트 안내 문구.
7. **레이아웃**: 360×640 / 390×844 / 768×1024 / 1280×800 / 가로 844×390 / **가로 800×360**에서 가로 스크롤 0, 보드·게이지·버튼이 화면 안, 터치 타깃 ≥44px, `--ui-h`·보드 크기 불변(이전 390 폭 366px / 360 폭 336px), 3·4차에서 고친 가로 모드 `.goal`/결과 버튼 보정 유지.
8. **성능**: `backdrop-filter` 개수, 칸당 `filter` 개수(허용: 물 보석 보정·선택 1개), 구름·CTA 애니메이션이 `transform`/`opacity`만 쓰는지 정적 점검. 가능하면 CDP로 **CPU 4× 스로틀** 상태에서 연쇄 매치·스킬 이펙트 중 프레임 드롭을 측정(불가하면 못했다고 명시).
9. **접근성·모션**: `prefers-reduced-motion` 에뮬레이션(CDP `Emulation.setEmulatedMedia`)으로 구름·CTA·힌트·펄스가 정지/축소되는지, `:focus-visible`이 배경별(하늘/흰 카드/어두운 트레이)로 보이는지(키보드 Tab).
10. **죽은 규칙·CSS 건전성**: `style.css`에 덮어쓰기 방침으로 남은 이전 규칙이 새 규칙과 충돌해 보이는 깨짐을 만드는지(예: `.gauge.full`의 `gaugePulse` 덮어쓰기), 사용하지 않는 `bg-jungle` 외 외부 URL 없음.
11. 사용자에게 보이는 문구·색 이름 등 오탈자.
