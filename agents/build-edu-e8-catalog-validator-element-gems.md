# Build 지침 E8 — 문제 카탈로그·검증기 (spec §21.3·§21.4.3·§21.5)

## 역할
교육용 문제 DB의 **카탈로그(`edu-data/catalog.js`)**, **검증 스크립트**, **검증기 시험**, **동기화 절차 문서**를 만든다. 사용자가 **spec §21을 승인**했다(2026-11-08). 이 산출물이 끝나면 **데이터 에이전트 4명(D3~D6)이 25개 소단원의 문제 파일을 만들고 네 검증기로 통과시킨다** — 그래서 검증기는 **명확하고 정확하고 빨라야** 한다. 동시에 E1(엔진)·E2(UI)·E3(선택 페이지)가 다른 파일을 만든다.

## 구현할 것
1. **`edu-data/catalog.js`**: `window.EDU_CATALOG`(스크립트 전역, `file://` 호환, ES module 금지, Node에서 `require`도 가능하게 `module.exports` 조건부 내보내기). spec §21.4.3의 구조 그대로: 과목 `soc`(사회) → 학년 3·4·5·6 → `term:1` `ready:false`('준비 중') + `term:2` `ready:true` → 대단원(`no`, `name`) → 소단원(`no`, `id`, `name`, `pages`, `count:60`, `file:'edu-data/q/{id}.js'`). **25개 소단원의 ID·이름·쪽수는 §21.3 표를 따르고, 이름·쪽수는 추출 텍스트의 제목 줄(예: `(1) 사회 변화로 달라진 생활 모습 (사회: 6-33쪽)`)과 대조해 일치함을 확인**한다(대단원 이름 포함). 과목·학기·소단원을 **항목 추가만으로** 늘릴 수 있어야 한다(코드 수정 불필요).
2. **`tools/validate-edu-data.js`**(Node, **의존성 없음**): `node tools/validate-edu-data.js [--source-dir <원문 폴더>] [--file <소단원 문제 파일 경로>…] [--json]`. §21.4.3의 **검증 스크립트 검사 항목 표를 모두 구현**(스키마 / 개수 60 / 비율(OX 22~26·mc 34~38·O/X 각 10~14·mc 정답 위치 각 7~11) / 길이 상한(3·4학년 vs 5·6학년) / 중복 / 2-그램 유사도 경고 / 사실 연결 / 금칙 / 민감어 경고 / 가독성 경고 / 재서술 14자 연속 일치(소단원당 3곳 이상이면 오류)). 문제 파일은 `window.EDU_Q` 등록 형식(§21.4.3)이므로 **`vm`으로 샌드박스 실행해 읽는다**(`window`가 있는 가짜 컨텍스트). 출력은 **사람이 읽기 쉬운 한국어**(소단원·문항 번호·규칙명·무엇이 문제인지·어떻게 고칠지 한 줄)와 `--json`. 종료 코드: 오류 있으면 1, 경고만이면 0. 민감어 목록(처단·학살·폭탄·사형·죽이·위안부 등)·어려운 한자어 목록·금칙 문구는 파일 상단 상수로(데이터 에이전트가 읽기 쉽게 주석). 기법 코드(`k`) 17종 목록과 학년별 길이는 상수로.
   - 소단원이 속한 학년은 파일 id(`soc-{학년}-…`)로 판별. 카탈로그에 없는 id·`file` 불일치는 오류.
   - **빠르게**: 25개 전체 검사가 1초 안팎.
3. **`test/edu-data.test.js`**(`node --test`): 정상 샘플(§21.4.5의 12개 문제를 사용해 소규모 합성 파일 또는 시험 모드의 완화 옵션으로)과 **나쁜 예 12종 이상**(스키마 오류, 개수 59, 정답 인덱스 범위 밖, 보기 중복, 길이 초과, 완전 중복, `f` 누락, 그림 의존 표현, 외부 링크, 보기에 '모두', 정답 위치 편중, 14자 겹침 등)이 **각각 올바른 규칙 이름으로 잡히는지**. 카탈로그 시험: 25개 소단원·ID 유일·`file` 경로 규칙·1학기 `ready:false` 구조·이름이 추출 텍스트 제목과 일치(원문 폴더가 있을 때만, 없으면 skip). **시험용 가짜 데이터는 시험 코드 안에서 메모리/임시 디렉터리(scratchpad)로 만들고 `edu-data/q/`에는 파일을 만들지 않는다.**
4. **`tools/SYNC.md`**(5줄 안팎): 일반용 변경을 교육용에 반영하는 절차(§21.2.5), 일반용 동결 권고, 일반용 무변경 검사식 `git diff base-general-v1 -- apps/element-gems ':!apps/element-gems/spec.md' ':!apps/element-gems/review.md'`.
5. `tools/` 폴더에 **데이터 에이전트용 안내 한 단락**을 `validate-edu-data.js` 파일 머리 주석으로 넣는다(사용법·오류/경고 읽는 법).

## 수용 기준(§21.10 E8)
검증기가 시험(나쁜 예 12종 포함) 통과, 카탈로그 25개 소단원·빈 학기(1학기) 구조, 25개 파일이 아직 없을 때 검증기가 "문제 파일 없음"을 **소단원별로 명확히 보고**(크래시 금지). 기존 `test/*.test.js` 60개는 그대로 통과(네가 건드리지 않음).
