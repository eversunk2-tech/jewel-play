## ⚠ 브라우저 사용 주의 (이전 사고 재발 방지)
- 과거에 `tabId` 없이 `javascript_tool`을 실행해 **배포 사이트(eversunk2-tech.github.io) 탭의 localStorage를 덮어쓴** 사고가 있었다. **모든 브라우저 호출에 `tabId`를 명시**하고, 시험은 **로컬 서버 탭(`http://localhost:<포트>/`)에서만** 한다. `localStorage`를 읽거나 쓰기 전에 `location.origin`이 로컬인지 확인한다. 배포 주소는 열지 않는다.

## 승인된 결정 (§17.10 열린 질문의 답)
1. **목표 점수 달성 즉시 클리어**(진행 중 연쇄 정산 뒤 "STAGE CLEAR!"). 시간 0까지 못 넘기면 실패. 시간 소진 순간의 정산 중 목표를 넘으면 클리어.
2. **별 등급 포함**: 클리어 시 남은 시간이 시작 시간의 ≥50%면 ★★★, ≥30%면 ★★, 그 외 ★.
3. **시작 시간 유지**: 초보 130초 / 중수 120초 / 고수 100초 (§17.2 표의 상한·보너스·게이지 값 그대로).
4. 레벨 9~10 목표는 §17.4 표 그대로(후에 실제 플레이 후 조정; 값은 `CONFIG.stages.targets` 한 곳에 모아 둔다).
5. 60초 판 시절의 `best`/`bestByLevel` 기록은 **지우지 않고 보존**(§17.7 규칙대로 화면에서는 숨김).

## 구현 순서 (§17.8 단계 분해를 따른다. 단계마다 확인)
1. **프리셋 갱신**: `CONFIG.difficulty[...]`의 시작/상한 시간, 시간 보너스(×25%), 게이지 최대치(§17.2), 감쇠 제거. 타이머 표시 `m:ss`(§17.6 규칙: 60초 이상). 타이머 바 비율, 10초 이하 경고 유지.
2. **스테이지 데이터·로직**: `CONFIG.stages.targets[difficulty][level]`(§17.4 표), 클리어/실패 판정(즉시 클리어, 정산 중 달성 처리), 별 계산, 레벨 잠금/해제 규칙, 같은 난이도 진행도 독립.
3. **UI**: 시작 화면(난이도 3버튼 + `시작` → 레벨 선택 화면 이동), **레벨 선택 화면**(1~10 격자, 잠금/별/최고 점수 표시, 뒤로 가기, 모바일 레이아웃), 게임 중 HUD(`레벨 N`, 목표 점수, **목표 진행 바**), 일시정지/결과 화면의 난이도·레벨 표시, 결과 화면(클리어: 점수·별·`다음 레벨`/`다시 하기`/`레벨 선택`, 실패: `다시 도전`/`레벨 선택`, 레벨 10 클리어 축하). 시작 화면 규칙 문구를 스테이지 안내로 교체(§17.6). 기존 컷인·BGM·효과음 흐름과 충돌 없게(클리어/실패/난이도 완료에 기존 `newbest`/`timeup` 등 효과음 재사용, 필요 시 매핑만 정리).
4. **저장/마이그레이션**: `progress`, `stages` 키 추가(§17.7), 기존 `level`(난이도)·`bestByLevel`·`best`와 이름 충돌 금지, 옛 데이터 로드 시 진행도 레벨 1부터, 손상 데이터·`localStorage` 차단 시 `try/catch`로 기본값.
5. **상호작용 점검**: 스킬/컷인/일시정지/탭 숨김/리셋/재시작에서 목표 달성·시간 종료가 겹칠 때 중복 처리(클리어와 실패가 동시에 뜨는 등)가 없게, 컷인 중 클리어 판정 보류 후 정산, 초보 자동 힌트·2×2 규칙 회귀 없음.
