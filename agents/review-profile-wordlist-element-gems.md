## 검증 항목
### (가) 프로필 흐름
1. 첫 실행 → 시작 화면이 먼저(프로필 화면 자동 진입 없음). 이름 변경 요청(`hidden=2`) 사용자만 수정 화면.
2. 프로필 없음 + [시작] → 팝업("프로필을 만들어 주세요"). [프로필 만들기] → 저장 → 레벨 선택으로 이어짐 / [프로필 없이 시작] → 게임 진행, **서버 요청 0건**(네트워크 로그로 확인) / ×·바깥·Esc → 시작 화면에 머무름·포커스 복귀 / 같은 접속에서 다시 [시작] → 팝업 없음 / 새로 열면 다시 팝업.
3. **프로필 없이 플레이한 진행이 나중에 프로필을 만들 때 한꺼번에 제출**되는지, 이미 프로필이 있으면 팝업이 없는지, `apiBase` 빔 → 팝업·칩·순위 버튼 없음 + 게임 동일.
4. 접근성: 포커스 가두기·`aria-modal`·`inert`, 키보드만으로 전체 흐름, 터치 타깃 ≥44px, `prefers-reduced-motion`(CDP 에뮬레이션으로 실제 확인), 대비 WCAG AA 수치 측정(Build가 못 한 항목).
5. 레이아웃 6개 뷰포트(360×640·390×844·768×1024·1280×800·844×390·800×360) 가로 스크롤 0.
6. **회귀(Build가 못 한 항목)**: 스테이지를 **실제로 클리어**해서 결과 화면·제출·컷인(스킬 발동)·일시정지까지. 시험용 상태 조작이 필요하면 scratchpad 복사본에서만 하고 프로젝트 파일에는 남기지 않는다. `game.js` diff가 훅 범위인지 확인.
7. 예전 `localStorage` 프로필 저장값(`skipped:true` 등) 호환, 손상된 저장에서 오류 없음.
