# Build 지침 M4-A — 일반용: "잠든 원소 정령 깨우기" 특별 레벨 프레임 (spec §27.6·§27.8·§27.9 M4, 기록 §30·§33·§34)

## 역할
너는 **Build 담당**(Sonnet 서브에이전트)이다. 일반용 `apps/element-gems/`에 **특별 레벨(5·10단계, 세 난이도 모두 6곳)의 정령 프레임**을 만든다. **게임 규칙·목표 값·점수·난이도·별·저장 구조는 한 글자도 바꾸지 않는다**(화면과 문구만 추가). 교육용 이식(M4-B)은 이 단계가 끝난 뒤 다른 에이전트가 하므로 **교육용 폴더는 읽기 전용**이다. 검증은 별도 Review가 하며, **네가 직접 확인한 것만 "확인함"** 으로 쓴다.
프로젝트 규칙은 `CLAUDE.md`, 진행 상황은 `docs/STATUS.md` §14를 먼저 읽는다. **정답지는 `apps/element-gems/spec.md`**: **§27.6(비폭력 프레임 F1 — 특히 27.6.1 구조·27.6.2 문구 가이드·27.6.3 에셋)**, §27.8(HUD·접근성), §27.9.3(시험), §27.10(검증 체크리스트 9·10), §33(초보는 점수제 표현만), §34(메뉴 승인 — 이번 범위 밖), `review.md` §24-9(M4에 반영할 R-M1 제안: 정령 패널은 SEQ 칩을 포함하고 높이 93px 이내). 줄 번호는 참고용이니 함수 이름으로 찾는다.

## 승인된 결정 (바꾸지 않는다)
- 프레임 = **F1 "잠든 원소 정령 깨우기"**(사용자 승인 2026-11-08). 보스·적·체력바·공격 같은 **전투 표현은 없다**. 정령 그림이 흑백(잠든 중)에서 단계마다 **컬러로 돌아오고** "깨어남 게이지"가 **차오른다**.
- **새 이미지·음원·글꼴 파일을 만들지 않는다.** 기존 `assets/gems/*.webp`(보석 6종)에 CSS 흑백 필터만 쓴다. **새 효과음도 없다** — 단계 완료는 기존 효과음 `praise-good`(필요하면 마지막 단계에 `praise-great`)와 CSS 빛 번짐만 쓴다.
- **정령 6마리** — 색 번호: 불 0 · 물 1 · 풀 2 · 번개 3 · 어둠 4 · 빛 5. 5단계/10단계: **초보 번개/빛, 중수 풀/불, 고수 물/어둠**. 이름은 `CONFIG.types[색].name` + " 정령"(예 "풀 정령").
- **단계 수 n**: 초보 = **점수 목표를 3등분**(n = 3, 목표의 1/3·2/3·3/3 지점에서 한 단계씩, 규칙 변화 없음 — spec §33에서 사용자 확인), 중수·고수 = **SEQ 미션의 부분 수**(`mission.parts.length`: 3 또는 4). 깨어남 단계 k = 끝난 단계 수(0..n), **한 판 안에서 줄어들지 않는다**(`max`로 보호).
  - 초보 k = `min(n, floor(점수 × n ÷ 목표))` (목표 = 그 레벨의 `state.target`, 점수는 내부 `state.score`). 중수·고수 k = SEQ에서 끝난 단계 수(`missionProgress().doneCount`와 같게 — 직접 확인).
- **초보 레벨은 점수제로만 표현한다**(§33): 초보 카드·HUD·결과에 미션·쉬어가기·"특별 레벨" 태그를 쓰지 않는다. 정령 패널과 단계 칸은 초보 5·10에도 **점수 기준 문구**로만("목표 점수의 1/3에 왔어요"). 쉬어가기(3·6·9)는 화면에 글자로 나오지 않는다(§34).
- **비폭력 문구 가이드(§27.6.2)** — 피하는 말: 보스, 적, 몬스터, 전투, 싸움, 대결, 공격, 때리다, 쓰러뜨리다, 처치, 무찌르다, 물리치다, 체력, HP, 데미지, 피해, 죽다, 사망, KO, 파괴, 부수다, 폭발시키다(정령에게), 패배, 졌다. 쓰는 말: 특별 레벨, 정령 친구, 도전, 힘을 모아 줘요, 깨워 줘요, 도와줘요, 깨어남 게이지, 단계, 컬러가 돌아와요, 반짝, 깨어나요, 고마워요. 실패 = "아직 잠이 덜 깼어요. 다시 도전해요!". **연출 금지**: 정령을 흔들거나 번쩍이게 하는 "피격" 효과, 붉은 점멸, 피해 숫자, 무기 모양. 완료 연출은 **컬러 복귀 + 부드러운 빛 번짐 + 감사 문구**만. (기존 스킬 이름 "화염 폭발" 등은 범위 밖이니 건드리지 않는다.)
- 별은 남은 시간 기준 그대로, 제한 시간·스킬·콤보·점수 규칙·미션 표·`goalMet()`·`finishStage` 판정은 불변. **새 저장 필드 없음**(`save` 구조·`buildSnapshot`·서버 전송 값 불변). 서버·`ranking*.js`·`nickname.js`는 읽기 전용.
- 전체 이용가·초등학생 이상이 읽는 **쉬운 말**. 색에만 의존하지 않는다(그림 + 글자 + "zZ"/✓). 터치 타깃 규칙은 입력 대상이 아닌 표시에는 적용 안 됨. `prefers-reduced-motion`이면 전환·번짐 없이 즉시 상태만 바뀐다. 무한 반복 애니메이션은 화면당 ≤ 3개(잠든 중 "zZ" 떠오름 하나까지만 허용, 감소 모션에서 0).

## 만들 것 (불변식을 지키면 세부 DOM·이름은 네가 정한다)
1. **데이터** `CONFIG.stages.spirit`: 난이도별 `{5: 색번호, 10: 색번호}` 표와 초보 단계 수 `easySteps: 3`. 주석에 spec §27.6·§33 근거. 화면 문구는 한 상수 `SPIRIT_TEXT`(함수 포함 가능)에 **모아서** 시험이 문구 전부를 검사할 수 있게 한다.
2. **순수 함수**(DOM 없음, 시험용 내보내기): `spiritOf(diff, stage)`(해당 없으면 null, 있으면 `{ type, name, steps }`), `spiritStep(info, score, target, mission)`(= k). 특별 레벨이 아닌 판에서는 정령 관련 DOM·상태가 전혀 없다.
3. **게임 화면 패널**(`index.html`에 `#spirit`, 숨김이 기본): 특별 레벨에서만 보인다. 구성 — 정령 그림(기존 `gemMarkup` 재사용, 56~76px, 필터 `grayscale((n−k)/n)`와 약한 어둡기, k < n이면 "zZ" 표시), 제목("잠든 풀 정령" → 다 깨면 "풀 정령이 깨어났어요!"), **깨어남 게이지 n칸**(채워진 칸 = k, 색뿐 아니라 칸 모양/✓로도 구분)과 글자 "깨어남 k/n", 그리고 **현재 요청**: 중수·고수는 SEQ **현재 단계 칩**(이름·진행 `12 / 30`, 기존 `drawMissionChip` 재사용)이 패널 안에 들어간다, 초보는 목표 점수 바(`#goal`의 점수 진행)가 패널 안/아래에 보인다. **패널 전체 높이 ≤ 93px**(= 칩 2개 높이, `--ui-h` 규칙은 `data-chips="2"`와 같은 값을 쓰거나 같은 방식으로 정한다). 기존 `#goal`/`#mission`의 역할(role=progressbar, aria-valuenow/max, 완료 알림)은 유지한다. 그림과 장식은 `aria-hidden`, 패널에는 읽히는 이름("특별 레벨, 잠든 풀 정령, 깨어남 1/3")을 준다.
4. **단계 완료 연출**: k가 늘 때마다(한 행동에서 여러 단계가 한꺼번에 끝나도 한 번만) ① 정령 필터가 부드럽게 컬러 쪽으로(0.6초 전환) ② 그림 둘레 빛 번짐 한 번(붉은색·흔들림 없음) ③ 효과음 `praise-good`(마지막 단계는 `praise-great`) ④ 낭독용 `role="status"`(polite)에 "풀 정령이 한 걸음 더 깨어났어요 (1/3)" / 마지막 "풀 정령이 깨어났어요! 고마워요". 특별 미션 레벨에서는 칩의 "미션 하나를 끝냈어요" 낭독과 **겹치지 않게** 정령 낭독이 대신한다(이중 낭독 금지, 일반 레벨의 기존 낭독은 그대로).
5. **결과 화면**(`#overlay-end`): 특별 레벨에서만 한 줄 `#end-spirit` — 클리어 "풀 정령이 깨어났어요! 고마워요", 실패 "아직 잠이 덜 깼어요. 다시 도전해요! (깨어남 1/3)". 특별 레벨이 아니면 숨김. 기존 `end-target`·별·언락 줄은 그대로. 중수·고수는 단계 ①②③ ✓ 표시가 있으면 좋지만 줄 넘침이 없을 때만(필수 아님).
6. **레벨 선택**: ① 설명판(`stageDetailInfo`)의 특별 레벨 hint에 "잠든 풀 정령 친구가 기다려요" 같은 한 줄(초보도 같은 문구, 미션·쉬어가기 표현 없음). ② 카드 `aria-label`에 정령 이름만 더한다(예 "레벨 5, 특별 레벨, 잠든 풀 정령, …" — 초보는 "특별 레벨"이라는 말 없이 "레벨 5, 잠든 번개 정령, 목표 …"). **카드의 보이는 모양은 이번에 바꾸지 않는다**(메뉴 개선 U-3이 곧 카드 스킨을 입히므로 `.sc-tag` 외 새 장식 금지). ③ **"깨운 정령 n/6" 한 줄 + 작은 정령 6개**(`aria-hidden`, 깨운 것은 컬러, 아닌 것은 흑백): 레벨 선택 화면 상단 요약 근처(`stages-summary` 곁)에 둔다. n은 `save.stages[난이도][4|9].stars > 0`인 칸의 수(세 난이도 합, 현재 선택 난이도와 무관)로 **계산**하고 새 저장 필드를 만들지 않는다. 낭독 가능한 글("깨운 정령 2마리 / 6마리")이 있어야 한다.
7. **새 CSS**는 `style.css` **끝에 블록 하나** `/* 정령 특별 레벨 (spec §27.6, M4) */`로, 클래스는 `.spirit*`/`.sp-*` 접두어로 격리한다(기존 규칙 수정 금지 — 높이 규칙 한 줄 추가는 허용). 교육용 `style.css`가 나중에 바이트 동일로 복사되므로 **교육용 전용 값은 쓰지 않는다**. 글자 대비는 WCAG AA 4.5:1 이상(기존 토큰 사용, 측정해서 보고).
