# Build 서브에이전트 지침 — 프로필 만들기 순서 변경 (메인 화면 먼저, [시작]에서 프로필 안내 팝업)

> 사용자 요청(2026-11-07)을 그대로 구현한다. 규칙·수치·서버는 바꾸지 않는다.

## 요구 (사용자 원문 요지)
"게임 메인화면이 먼저 나오고, 프로필 설정을 그 다음에 하도록 순서를 바꿔 줘. 메인 화면에서 그냥 '시작'을 누르면 '프로필을 생성하세요'라는 팝업 문구가 나오게 해 줘. **프로필 없이 하기**도 선택사항으로 두고, 그러면 **랭킹 반영 없이** 게임을 시작해 줘."

## 새 동작 (확정)
1. **첫 실행 때 프로필 화면이 먼저 뜨지 않는다.** 항상 시작(메인) 화면이 먼저 나온다. (현재: 프로필 없고 `apiBase`가 있으면 첫 화면이 `#screen-profile` — 이 자동 진입을 제거한다.)
2. 프로필이 **없고** 랭킹이 켜져 있을 때(`apiBase` 있음) 시작 화면의 **[시작]**(난이도·레벨 선택으로 가는 기본 버튼)을 누르면 **팝업(모달)** 이 뜬다.
   - 제목: **"프로필을 만들어 주세요"** (사용자 문구의 쉬운 말 형태). 설명 한 줄: "프로필을 만들면 명예의 전당에 내 이름과 별이 올라가요."
   - 버튼 3개: **[프로필 만들기]**(주 버튼) / **[프로필 없이 시작]**(보조) / 닫기(×) 또는 바깥 눌러 닫기 = 시작 화면에 머무름(게임 안 들어감).
   - **[프로필 만들기]** → 기존 `#screen-profile`로 이동. 저장에 성공하면 원래 가려던 곳(난이도·레벨 선택, [시작]이 가는 곳)으로 이어간다. 프로필 화면의 [나중에 할래요]/뒤로가기는 시작 화면으로 돌아온다(게임으로 강제 진입하지 않음).
   - **[프로필 없이 시작]** → **랭킹 반영 없이** 바로 게임 흐름으로 들어간다. 이 상태에서는 서버로 아무것도 제출하지 않는다(진행 제출·프로필 제출 모두). 이 선택은 **이 접속(페이지를 연 동안)에만** 기억해 같은 접속 중에는 팝업이 다시 뜨지 않는다(메모리 또는 `sessionStorage`, 영구 저장하지 않는다 → 다음에 열면 팝업이 다시 나온다). 기존 `localStorage` 프로필·동기화 구조는 바꾸지 않는다.
3. **프로필이 이미 있으면** 팝업 없이 지금처럼 바로 진행한다. **`apiBase`가 비어 있으면** 프로필·순위 UI와 팝업이 모두 없고 게임이 지금과 완전히 같다.
4. 시작 화면에는 프로필이 없을 때 **[프로필 만들기]** 칩(이미 있는 내 프로필 칩 자리)을 보여 줘서, 팝업을 건너뛴 사람도 나중에 만들 수 있게 한다. 프로필을 나중에 만들면 기존대로 **그때까지의 진행 전체가 한 번에 제출**된다(spec §19.3, 변경 없음).
5. [명예의 전당] 버튼은 지금처럼 프로필 없이도 열 수 있다(보기만). 순위표의 "내 순위" 줄 등 프로필 없는 상태 표시는 지금 동작을 유지한다.
6. 팝업은 초등학생이 읽는 쉬운 말, 중립 톤, 접근성: `role="dialog"`, `aria-modal`, 제목 연결, 열릴 때 주 버튼에 포커스, **Tab 포커스 가두기**, **Esc = 닫기**, 닫힌 뒤 [시작] 버튼으로 포커스 복귀, 터치 타깃 ≥44px, `prefers-reduced-motion` 존중, 360×640·390×844·768×1024·1280×800·가로 844×390·800×360에서 잘림·가로 스크롤 없음, WCAG AA 대비. 팝업 뒤 화면은 눌리지 않게 한다(딤).
7. 스킬 컷인·일시정지 등 다른 오버레이와 충돌하지 않게 한다(팝업은 시작 화면에서만 뜬다).
