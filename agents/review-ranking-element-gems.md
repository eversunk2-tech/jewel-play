## 검증 항목
1. **spec §19.11 체크리스트 전체**를 표(항목 / 결과 / 근거)로. 항목마다 직접 실행한 명령·입력·관찰을 적는다.
2. **닉네임 검증(최우선 적대적 시험)**: A의 시험 벡터를 그대로 믿지 말고 **독립적으로 새 우회 입력 50개 이상**을 만들어 `validateNick`에 넣는다(자모 분리·초성·띄어쓰기·특수문자·전각/호환 문자·숫자/영문 치환·반복·혼용·한글+영문 결합·제로폭 문자·정규화 변형). 통과한 부적절 후보는 모두 기록(알려진 한계인 음절 쪼개기와 구분). **오탐**(정상 닉네임 40개 이상: `반달곰`, `초코우유`, `class`, `pass`, `하하` 등)도 확인. 서버(`core.js`)와 클라이언트가 **같은 입력에 같은 결과**인지 비교. 안내 문구가 금칙어를 알려 주지 않고 초등학생이 이해할 말인지.
3. **서버 조작 방어**: 목 서버를 띄워 `curl`/Node로 `left=9999`·음수·소수·문자열·배열 길이 오류·난이도 키 누락, 레벨 10만 클리어(연쇄 위반), 별만 위조, 감소 제출, 오래된 스냅샷 재전송, 2대 기기 병합, 3초 간격 위반, 2,048B 초과(413), 닉네임 하루 2회(KST 경계), 부적절 닉네임 서버 재검증을 시험한다. 별↔`left` 임계값 경계 ±1이 `game.js`의 `CONFIG`/`starsFor`와 일치하는지 코드로 대조(초보 39/65, 중수 36/60, 고수 30/50).
4. **개인정보·비밀**: DB 덤프에 이름·IP·UA·playerId 원본이 없는지, 로그·응답에 `pid`/`pub`이 없는지, `git grep`·파일 전체 grep으로 비밀키·토큰·실제 DB ID·`.dev.vars` 없음, `.gitignore` 동작, `dist/worker.js`에 비밀 없음, `/api/admin/*`가 키 미설정이면 404·틀린 키 제한. `wrangler.toml`의 `database_id`가 자리표시자인지.
5. **CORS·응답 형식**: 허용 오리진 OK, 목록 밖 `Origin` 403, `Vary: Origin`, `OPTIONS` 204, `text/plain` POST가 preflight 없이 동작하는지, 오류 응답이 JSON 형식을 지키는지.
6. **순위 정확성**: 정렬(별 → 남은 시간 합 → 먼저 달성 → id), 동점 4시나리오, 난이도 탭/전체 합, 숨김·별 0 제외, 상위 50, `of`, 내 순위(상위 안/밖/프로필 없음/숨김)가 SQL COUNT와 정렬 결과에서 일치. 닉네임이 `textContent`로만 렌더(HTML 주입 불가).
7. **클라이언트 오프라인·회귀**: `apiBase` 빈 값 ⇒ 프로필·순위 UI **전혀 없음** + 게임이 기존과 동일(§17·§18 흐름: 시작 → 난이도 → 레벨 → 게임 → 스킬 6종 컷인 → 일시정지 → 클리어/TIME UP → 결과). 서버 중지/지연/5xx/비 JSON/타임아웃/503에서 **게임 입력·애니메이션 지연 없음**, 순위표 오류·캐시 배너, 복구 후 자동 제출, 오프라인에서 여러 번 깨도 마지막 스냅샷 한 번, single-flight, 결과 표시 1.2초 뒤 제출·컷인과 충돌 없음.
8. **저장 마이그레이션**: `game.js` Node 시험 재실행, `left` 없는 옛 저장 → 하한값, `best/bestByLevel/level` 보존, 깨진 JSON/`stages` 오류에도 게임 가능, `starsFor` 결과가 이전과 동일. **게임 규칙·수치가 바뀌지 않았는지** `git diff apps/element-gems/game.js`를 훑어 훅·저장 확장 외 변경이 없는지 확인한다.
