3. **불변식 I2~I10**를 시험·코드로 확인(null 없음·값 0~5, 유효한 수는 기존 후처리가 보장, `auto=0`이면 새 칸이 줄·2×2를 완성하지 않음, 스킬 6종 충전 대칭(색 가중 없음), 시계·점수·게이지·별 규칙 불변, **반응형 아님**(입력은 난이도·레벨·보드·난수뿐), 이미 있는 보석은 바뀌지 않음, 결정적). 호출부(`startStage`·`resetState`·`buildBoard`·`dropAndRefill`·교육용 `planRefill`)를 **직접 읽고** `state.board`가 모든 경로(처음 시작·다시 하기·다음 레벨·**스킬 뒤 리필**·재섞기)에서 올바르게 정해지고 오래된 값이 남지 않는지 점검한다.
4. **교육용 합성(§26.9, E1~E5)**: ? 여부를 `pickRefillTypes`로 먼저 → ? 칸 선채움 → 나머지를 `refillStructured` → 소비 순서 반환. ? 개수 ≤ `CONFIG.edu.wild.max`, 첫 행동 확정 등장 유지, `spawn=0`이면 ? 없이 일반용과 난수 소비 동일, `auto=0` 보장은 일반 보석끼리만, ?는 `pair`에서 색으로 세지 않음, 시작 보드에 ? 없음. **`pickRefillTypesStructured`가 `pickRefillTypes`의 난수 소비·결과 규칙을 바꾸지 않는지** 읽고 시험한다.
5. **시험 직접 실행**(Node 24는 **글롭**): 일반용 `node --test apps/element-gems/test/*.test.js`(기대 **142**), 교육용 `node --test apps/element-gems-edu/test/*.test.js`(기대 **331 중 330 통과·건너뜀 1·실패 0**), 서버 `node --test apps/element-gems/server/test/*.test.js`(기대 **65**). **단언이 약해지지 않았는지**: `git diff`로 기존 시험 파일 변경을 대조한다 — 특히 `edu-engine.test.js` 패치가 ① **단언을 지우거나 약화하지 않았는지** ② `cfg.board.enabled = false`가 시나리오 시험(Math.random 강제값으로 새 칸을 정하는 시험)의 **원래 의도를 보존**하는지(구조를 끈 경로가 정확히 옛 동작이라 그 시험이 여전히 같은 메커니즘을 검사하는가) ③ 구조를 **켠** 경로에서 같은 메커니즘(NO MOVES 처리·스킬 행동 연쇄·문제 뒤 흐름)이 신규 시험이나 다른 시험으로 덮이는가 ④ 목표 3000→6000이 "일반용과 똑같이 흘러간다" 시험의 단언 강도를 바꾸지 않았는가(건전성 단언 `행동 수 > 5`를 만족시키려는 설정 변경임)를 판정한다. 약화로 판단되면 **고치지 말고** 제안으로 남긴다(메인 세션 결정).
6. **독립 시뮬레이션 재검증 (±5%p)**: 실제 `game.js` 규칙 함수를 `require`해 **네 스크립트**로(구조 함수가 이제 `game.js`에 있으니 `boardParams`·`refillStructured`·`generateBoardStructured`를 직접 쓸 수 있다). 모델은 spec §17.5·§25 머리말·§26.5(수는 무작위 또는 3개 중 최선, 수당 생각시간 평균 ±0.6초 균등, 스킬 확률 0/30/60%와 1.2초 지연, 컷인 1.3초 시계 정지, 불·풀 조준 무작위). **시드는 20,000,000 이상으로 새로**(Plan 1,100,000~·1,300,000~, Build 별도), 셀당 **≥ 1,200판**(최소 600). 일반용 §25.6 목표 점수 30칸에서 **대표 3종**(초보 3.0초·스킬 가끔·무작위 / 중수 3.0초·스킬·무작위 / 고수 3.0초·스킬·최선3)의 **균등(구조 끔) 대 구조 켬 클리어율 차이 |Δ|가 칸마다 ≤ 5%p**인지(§26.5 측정: 평균 초보 2.0 / 중수 1.2 / 고수 3.7%p, 고수 일부 칸은 더 클 수 있음 — **벗어나는 칸은 원인(표본 오차 / 모델 차이 / 실제 문제)을 적는다**), 9종 플레이어 전체의 평균·최대 |Δ|. 조건·시드·판 수를 밝힌다.
7. **구조 지표 단조성(§26.6)**: M1 평균 유효 수↓·M2 막힘 비율↑·M3 같은 색 이웃쌍·M4 4개 이상 매치 비율이 30칸에서 단조(위반 0 또는 표본 잡음 안), 같은 레벨에서 난이도 간 격차(유효 수 2개 이상), 별 분포(3★ 비율)가 §26.7과 같은 수준. **구간 만족률 측정 방법 차이**: Build 에이전트가 "리필 직전 상태(안정된 균등 보드에서 줄 3~5개 지운 뒤 중력)" 방식에서는 spec과 같은 값(s≥0.5 100%, −0.5 99.4%, −1 93.2%, −1.5 86.7%)을, "판 진행 중 모든 리필" 방식에서는 더 낮은 값(초보 +2 약 96%, 고수 −1.5 약 84~86%)을 얻었다 — **두 방법으로 다시 재어 어느 쪽이 실제 게임 상황을 대표하는지** 판단하고, 시험 하한(97/96.5/90/84%)이 적절한지 의견을 낸다.
