# 추가 지침 1 — 사용자 번복(2026-11-08): 레벨 선택도 B안이 아니라 **기존 페이지가 더 좋다** → 레벨 선택까지 포함해 새 시안 구성 (원 지침의 일부를 **대체**)

원 지침: `agents/plan-ui-refresh-v2-element-gems.md`. 충돌하면 **이 문서가 우선**이다. 이미 만든 시안·쓴 §32 내용은 이 범위에 맞게 고친다(§32는 네가 쓰는 §이니 고쳐도 된다. §1~§31은 읽기만).

## 사용자 말 (원문)
"다시 생각해보니 **레벨선택도 b안 말고 기존 페이지가 더 좋은 것 같아. 이 페이지까지 포함해서 시안 구성해줘.**"

## 대체되는 것
1. 원 지침의 **"레벨 선택 화면 = §29의 B안으로 확정"**과 "모든 시안에 B(가로 지도)를 넣는다"는 **철회됨**(사용자 번복, §32 머리말에 "§29 B 확정은 철회됨 — 사용자 번복: 기존 레벨 선택 페이지가 더 좋다"). §29의 A·B·C·D는 **모두 철회**된 상태이며, **길 지도형은 후보 아이디어 중 하나일 뿐**(다시 쓰려면 "현재 레벨 선택 페이지보다 확실히 낫다"는 근거를 새로 보여야 한다).
2. **레벨 선택 화면은 이제 다른 메뉴 화면과 똑같은 대상(IN)**이다. 새 시안 V1·V2·V3 **모두에 레벨 선택 화면을 새로 설계해서 넣는다**(자유롭게, 지도형이든 카드형이든 — 단 현재 페이지보다 한눈에 확실히 나아야 한다). 기준은 **태블릿 가로(1180×820)에서 다시 찍은 현재 레벨 선택 페이지**다. 현재 페이지가 사용자가 좋아하는 화면이므로 **가장 엄격하게 자기 비판**한다: 현재와 나란히 놓고 "확실히 더 낫다"를 못 말하면 그 안의 레벨 선택은 **"현재 유지"**로 둔다(그것도 허용되는 결론 — 안마다 레벨 선택이 "새 설계 / 현재 유지 + 소폭 변경" 중 무엇인지 솔직하게 적는다). 안 전체가 약하면 약하다고 쓴다.

## 이 화면에서 반드시 고려할 것 (진행 중인 §27과의 접점)
- §27 M2가 레벨 카드에 **미션 요약(수집·큰 매치·연쇄 등 아이콘/문구)**, **쉬어가기(3·6·9단계) 표시**, **특별 레벨(5·10단계, "잠든 원소 정령") 표시**, 별·잠김·현재 레벨 상태를 넣는다(spec §27.5·§27.8, 현재는 `.stage-detail`·레벨 카드 구조). 새 설계는 **이 정보들이 들어갈 자리**를 갖춰야 한다. 시안에 **상태 4종**(완료·현재·잠김·특별)과 **초보(점수 목표)·중수/고수(미션)** 카드 모양 차이를 모두 보여 준다. §27 M2와 같은 화면이므로 "§27 M2 전/후/동시" 순서 권장은 그대로 쓴다(이전에 B 확정을 전제로 쓴 부분은 이 번복에 맞게 고친다).
- 교육용 레벨 선택(문제 양 선택·학습 조건 표시)도 같은 구조다.
