## 촬영할 4컷 (파일명)
1. **`shot-1-game.png` 게임 화면(와이드)**: 초보 레벨 3~4 정도의 플레이 중간. 보드에 보석이 가득하고, 오른쪽 패널의 **원소 게이지 6줄(스킬 이름+설명)** 이 보이며, 게이지가 **여러 개 부분적으로 차 있고 1~2개는 가득 찬(★)** 상태, 점수·연쇄 표시가 보이면 좋다. 보드가 연쇄로 터지는 순간이면 더 좋다. 봇(`bot.js`)이 몇 번 매치를 하게 하거나 사본의 저장·상태를 조작해도 된다(사본에서만).
2. **`shot-2-cutin.png` 스킬 컷인**: 불 또는 번개 컷인이 **캐릭터와 말풍선까지 뚜렷하게** 보이는 순간(애니메이션 중간~끝 프레임을 여러 장 찍어 가장 선명한 것 선택). 뒤 보드가 딤으로 보이는 구도.
3. **`shot-3-levels.png` 레벨 선택**: 난이도 탭(초보/중수/고수)과 **레벨 1~10 카드, 별(★)이 여러 레벨에 다양하게** 채워진 상태(예: 1~6 클리어, 별 3·2개 섞임, 7 해금, 8~10 잠김). 사본의 저장값으로 구성.
4. **`shot-4-hall.png` 명예의 전당**: 목 서버에 라이벌 10명(`apps/element-gems/server/tools/seed-hall.js --api http://127.0.0.1:<포트> --apply --pids <scratchpad 경로>`로 등록)과 **내 프로필 1개**(닉네임 예: `하늘별`, 아바타 아무거나, 별 점수 약 9로 순위표 중간쯤)를 넣고, 전체 탭 + 내 순위 바가 보이게. 닉네임·아바타는 일반 이용자처럼 보이는 정상 이름만 사용.
- 모든 컷은 콘솔 오류 0, 가로 스크롤 0인지 확인한다. 개인정보·실제 계정·서버 주소가 화면에 나오지 않게 한다.

## 후처리
- 원본 PNG(1366×768)를 확인한 뒤 웹용으로 **JPEG 또는 WebP, 장당 약 250KB 이하**(폭 1366 유지, 품질 80대)로 변환한다(`sips -s format jpeg -s formatOptions 80 …` 등 macOS 기본 도구 사용 가능, 불가하면 가능한 방법으로). 변환본을 `docs/intro/shot-1-game.jpg`, `shot-2-cutin.jpg`, `shot-3-levels.jpg`, `shot-4-hall.jpg`(확장자는 실제 형식에 맞게)로 **프로젝트 `docs/intro/`에 복사**한다. 이 4개 외에 프로젝트 폴더에 파일을 만들지 않는다.
- 각 장을 직접 열어 눈으로 확인하고(잘림, 깜빡임, 흐림, 빈 보드, 어색한 상태 없음) 맘에 들지 않으면 다시 찍는다.
