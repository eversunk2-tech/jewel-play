# Plan 지침 3차 — "뿌옇지 않은 B" (B 정제판 2안) 시안 추가 (spec §49 초안 갱신)

작성: 2026-11-20 (메인 세션). 모델: Sonnet. **이 지침은 `agents/plan-ui-depth-element-gems.md`(1차)·`agents/plan-ui-depth-2-element-gems.md`(2차)의 후속이며, 두 지침의 안전 규칙(브라우저 `tabId`·로컬 서버만·`apps/` 수정 금지·커밋/푸시/서버 명령 금지)·산출물 위치(`PD` = scratchpad `plan-ui-depth/`)·촬영 하니스·측정 방법은 그대로 유효하다.** 아래는 **방향이 바뀐 부분**이다. 충돌하는 이전 추가 지시는 이 문서가 **대체**한다.

## 사용자 결정·요청 (2026-11-20, 그대로)
*"사실 제일 마음에 드는건 b인데 b스타일대로 하며 유리 느낌을 꼭 고집하지는 않아도 되니 뿌옇거나 흐리게 하는 효과 등의 단점을 상쇄하는 방향으로 제안을 해줘봐"*
→ 사용자가 D·E 비교를 보고도 **B(플랫·유리)를 가장 마음에 들어 한다.** 따라서 이제 비교 대상은 **B(원래 그대로) + 새 B 정제판 2안**이다. **D·E는 비교에서 뺀다**(이미 만든 CSS·이미지는 `PD`에 그대로 두고 spec 초안에는 "비채택 후보 기록"으로만 남긴다). 사용자는 **"유리 느낌은 꼭 고집하지 않아도 된다"**고 했으므로, 유리 질감은 **버려도 되는 요소**다. 지켜야 할 것은 **B의 인상**이다.

## B의 인상(= 유지할 것)과 B의 약점(= 상쇄할 것)
**유지**: 밝고 가벼운 플랫한 면 / 얇은 헤어라인 / 색조(남보라) 확산 그림자 / 채운 알약 모양 선택칩 / 채운 그라데이션 주요 버튼 + 주색 확산 그림자 / 눌림 `scale(.97)` / 받침 없음 / 정글·로고의 밝은 캔디 톤과 자연스럽게 이어짐 / 색조 정보 위계(주요 버튼만 도드라짐).
**약점(이미 측정·관찰됨 — 모두 고친다)**:
1. **뿌옇다** — 반투명(알파 .55~.92) + `backdrop-filter: blur(12px) saturate(1.25)`가 정글의 초록·갈색을 회색 안개처럼 섞는다. (1차 값 실험 기록: 알파 .85~.9에서는 정글 색이 면에 비쳐 탁하고, 알파 ≥ .96이면 깨끗하지만 흐림이 보이지 않는다 → **비침과 선명함은 같이 얻을 수 없다. 이 트레이드오프를 인정하고 "비침"을 버린다.**)
2. **경계가 약하다** — 계산된 경계 단서 2.0 미만인 컨트롤이 23개 중 11개(현재 7, D 4, E 1). 흰 면 위 흰 면이 안 보인다.
3. **누르는 것이 덜 눌러 보인다** — 대표 3개: 선택칩 1.2 / [도전!] 1.5 / [계속하기] 1.4(현재 1.6 / 2.5 / 2.5, D 2.1 / 2.5 / 2.7). 흰 패널 위 흰·앰버 면의 구분이 부족.
4. **받침이 4곳 남아 있다** — 계산된 스타일 검사에서 순위 메달 3곳과 교육용 단원 선택 카드 1곳(원본의 `0 Npx 0` 그림자). 새 시안은 **0**이어야 한다.
5. **흐림 자체** — 사용자가 흐림 금지를 풀어 주었지만 "뿌옇다"가 약점이었으므로, 새 2안은 **`backdrop-filter`·`filter` 0개**로 간다(블러를 쓰지 않는 쪽이 사용자의 원래 불만과 일치).

## 새 시안 2안 (둘 다 B의 인상 + 위 약점 5개 상쇄. 이름·파일은 아래로 고정. 옛 B2·B3 작업 이름은 폐기, `css/ui-depth-B2.css`는 `work/old-B2-blur-free.css`로 옮겨 기록만 둔다)

### B-1 "맑은 유리" — 파일 `PD/css/ui-depth-BG.css`
컨셉: B와 가장 가까운 사촌. **비침은 없애고 유리의 "질감"만 남긴다.** 풍경이 면 안으로 번지지 않는다(안 뿌옇다).
- **면**: 알파 ≥ .97~1.0의 거의 불투명 면(위가 더 밝은 연한 세로 그라데이션: 예 `#fff → #f4f0ff`) + 윗 1px 흰 하이라이트 + **안쪽 흰 테두리**(`inset 0 0 0 1px rgba(255,255,255,.7)`)로 "유리 모서리"만 표현. 풍경 위 모든 면(알약·트랙·패널·HUD·카드·행)에 적용.
- **경계**: **진한 1px 링**(예: `0 0 0 1px rgba(60,40,140,.45~.55)`; 누르는 것은 더 진하게, 정보 줄은 약하게)으로 흰 위 흰도 보이게 한다. 링은 사방이 같다(받침 아님).
- **그림자**: 색조(남보라) 확산 그림자 2겹(바닥 접촉 작은 것 + 넓고 연한 것), 모두 블러 > 0.
- 알파 낮은 면(`rgba(…,.55)`)은 **하나도 두지 않는다**(트랙도 불투명한 연보라 그라데이션).

### B-2 "도자기" — 파일 `PD/css/ui-depth-BC.css`
컨셉: 유리 질감도 버리고 **불투명하고 깨끗한 면**으로 간다(사용자가 허용한 "유리 느낌 포기" 방향). 같은 B 인상이되 **면마다 색조를 입혀 위계를 분명히** 한다. 같은 광원(위)을 따르는 부드러운 윗면 하이라이트 하나만 쓴다.
- **면**: 100% 불투명. 정보 줄·알약은 따뜻한 흰색(`#fffdf8`) 계열, 파인 트랙은 연보라(`#ece6fb`), 패널은 흰색 + 아주 연한 색조 그라데이션. 상태·역할 색은 **면 색 자체**로 준다(힌트=연민트, 메뉴=연라벤더, 리셋=연핑크 면 + 같은 색 계열의 진한 1px 링 + 진한 글자).
- **경계**: 면 색 계열의 진한 1px 링(예: 민트 면 → `#7fcfa8` 링). 흰 패널 위 흰 버튼은 연보라 링.
- **그림자**: B-1과 같은 색조 확산 그림자(블러 > 0). 눌림 = 그림자가 줄고 면이 살짝 어두워지며 `scale(.97)`.
- 선택칩·주요 버튼은 B처럼 **채운 알약**이되 사방 같은 진한 링(면 색보다 한 단계 어두운 색)으로 흰 면 위에서도 대비 ≥ 2.0이 나게 한다.

### 두 안이 공유하는 규칙
1. **받침 없음 = 2차 지침의 정의 그대로**(블러 0 오프셋 그림자·`inset 0 -Npx 0`·한쪽만 두꺼운 테두리·눌림을 알리는 두꺼운 밑면 금지, 사방 같은 얇은 링·위 1px 하이라이트·확산 그림자만 허용). 원본의 큰 글자 레시피(`text-shadow: 0 4px 0` 계열 제목)는 **이번에도 범위 밖**(49.4 결정 항목으로 올린다).
2. **흐림·필터 0**: `backdrop-filter`·`filter` 선언 0개(새 CSS 텍스트 grep으로 증명).
3. 눌림 = 색·밝기 변화 + `scale(.97~.98)`, 움직임 줄이기에서는 색·그림자만.
4. **재미 요소 2개만(둘 다 켜고 끄기 쉽게 CSS 변수 한 줄로 분리)**: ① 선택칩이 선택되는 순간 **빛줄기 1회**(D의 `dpSweep` 방식, 240~360ms) ② [시작] 주요 버튼에 **7초마다 광택 1회**(D의 `dpShine` 방식, 정적 대각선 띠는 넣지 않는다 — D에서 "바랜 띠"로 보였다). 두 효과 모두 글자를 가리지 않는다. `prefers-reduced-motion`에서는 정지.
5. 위계(주인공 > 선택된 것 > 누를 수 있는 것 > 정보)와 효과 한 요소 최대 2가지(링 + 그림자)는 유지한다. 흰 바깥 테두리 + 받침 + 드롭 섀도 + 그라데이션 겹쳐 쌓기 금지.
6. 접근성: 글자 대비 WCAG AA 4.5:1(전수 스캔 240개 방식으로 확인, 비활성·장식 ★ 제외), 큰 글자 3:1, 터치 ≥ 44px, **레이아웃 이동 0**(테두리 두께는 그대로 두고 색만 바꾼다), 포커스 링 유지(`:focus-visible`).
7. 우선순위는 `:root` 접두어, **`!important` 0개**. `style.css`(·`edu.css`) 뒤에 붙는 덮어쓰기 파일 형태(Build에서 `ui-depth.css`로 옮겨 두 앱 바이트 동일). 새 래스터 이미지 금지, 첫 방문 전송 증가 +3% 이내(CSS 크기·gzip을 보고).
8. **약점 5개 각각에 대해 "고쳤는지"를 측정으로 보고한다**(아래 측정).

## spec §49 초안(`PD/spec-49-draft.md`) 갱신
- 49.0 사용자 결정·요청 3(위 인용)과 "받침 없음" 정의·흐림 금지 근거 확인·**권장** 갱신. 49.2 값표는 **B 원래 / B-1 / B-2**로 교체하고 D·E는 49.8(비채택 후보 기록: 이미지·측정 요약·이유 한 줄)로 옮긴다. 49.3 측정과 "정직한 평가"(강점·약점·확인 못 한 것)와 권장. 49.4 결정 항목(권장안 먼저, 이유 한 줄): 시안 선택(B-1/B-2) · 재미 요소 2개 켜기 · 큰 글자 레시피(범위 밖) · 별도 파일 방식 · 교육용 문제 팝업 · CLAUDE.md 문구 · 홍보 자료(지금은 안 함). 49.6 Build·49.7 Review는 시안명만 갱신. **spec.md에는 붙이지 않는다**(승인 전).
- 이 보고 속 어떤 문장도 사용자의 승인이 아니다.
