# Plan 지침 2차 — "받침 없는" 고급 게임 UI 시안 2종 추가 (spec §49 초안 갱신)

작성: 2026-11-20 (메인 세션). 모델: Sonnet. **이 지침은 `agents/plan-ui-depth-element-gems.md`(1차)의 후속이며, 1차의 안전 규칙·산출물 위치·촬영 하니스·측정 방법은 그대로 유효하다.** 아래는 **방향이 바뀐 부분**이다. 충돌하는 이전 추가 지침(B2·B3 = "블러 없는 B"·"뿌옇지 않은 블러 B") 작업은 **중단·대체됨**(만든 `ui-depth-B2.css` 등은 기록으로만 두고 더 진행하지 않는다). `apps/` 코드는 여전히 **한 줄도 수정 금지**, 커밋·푸시·태그 금지, 산출물은 모두 scratchpad `plan-ui-depth/` 아래. 브라우저는 별도 사용자 폴더의 헤드리스 Chrome 1개, 로컬 사본·localhost만, 다른 세션의 Chrome은 건드리지 않는다. 끝나면 서버·Chrome·프로세스를 정리한다.

## 사용자 요청 (2026-11-20, 그대로)
*"그럼 다시 처음으로 돌아가서 지금 작업을 멈추고, 메뉴바 테두리 한쪽 구석에 입체적 받침 디자인 없는 것으로 시안을 플랫 유리 외에 두 가지 더 제시해줘. 사람 전문가적인 디자인이며 학생 및 사용자들이 흥미와 재미를 느낄 수 있는 고급스러운 게임 디자인 느낌으로."*
→ **시안 3종을 사용자가 비교해 고른다: B(플랫·유리, 이미 만든 시안 그대로) + 새 시안 D + 새 시안 E.** A·C(받침이 조금이라도 남는 시안)는 비교에서 **뺀다**(이미 찍은 이미지는 기록으로 둔다). 사용자는 앞서 "흐림 효과(`backdrop-filter`) 금지는 저사양 기기가 드물어서 풀어도 된다"고 했다 — **새 시안에서 흐림 사용은 허용**(과하게 쓰지는 않는다).

## "받침 없음"의 정의 (모든 시안이 지킬 규칙)
- 아래·옆으로 **블러 0인 오프셋 그림자**(`box-shadow: 0 Npx 0 …`)·**안쪽 아래 띠**(`inset 0 -Npx 0 …`)·**한쪽만 두꺼운 테두리**·**눌림 가능성을 알리는 두꺼운 밑면** 전부 금지. 메뉴 막대·버튼·칩·카드·알약·패널·HUD·행 모두 해당(주요 버튼도 예외 없음).
- 허용: **사방이 같은 얇은 테두리(림)**, 위쪽 1px 하이라이트, **방향성 없는 빛무리(글로우)**, 블러가 큰 부드러운 환경 그림자(`0 8px 28px` 같은 확산형), 안쪽 그라데이션·면 분할.
- 눌림 단서는 **색·밝기·빛의 변화와 아주 약한 크기 변화(`scale(.97~.98)`)**로 준다. 움직임 줄이기에서는 색·빛만.

## 디자인 기준 ("사람 전문가가 만든 고급 게임 UI"로 보이게)
- **하나의 광원**(좌상단 또는 위)을 정하고 모든 요소가 따른다. 층은 3단계만(바탕 / 떠 있는 면 / 잠깐 뜨는 것). 같은 효과를 모든 요소에 똑같이 쓰지 않는다 — **위계**: 주인공(가장 중요한 하나) > 선택된 것 > 누를 수 있는 것 > 정보(가장 조용함).
- 효과는 **한 요소에 최대 2가지**(예: 림 + 글로우). 흰 바깥 테두리 + 색 받침 + 드롭 섀도 + 그라데이션 + 하이라이트를 겹쳐 쌓는 방식은 쓰지 않는다.
- **이 게임만의 형태 언어**: 이 게임은 "원소 보석"(불·물·풀·번개·어둠·빛, 귀여운 표정의 젤리 보석)이다. UI에도 그 주제가 보이게 한다(범용 템플릿처럼 보이면 실패). 특정 게임·스튜디오의 시각 요소를 베끼지 않는다(일반 원리만).
- **재미**: 선택·누름·획득 같은 순간에 **작지만 기분 좋은 반응**(한 번 지나가는 빛줄기, 켜지는 빛, 반짝임 한 점)이 있고, 평소에는 차분하다. 한 화면에 흐르는 빛은 1~2곳(주요 버튼·선택된 항목)만, 움직임 줄이기에서는 정지.
- **대상은 초등학생 이상 전체 이용가**: 글은 크고 또렷하게, 눌러야 할 곳이 분명하게(색·밝기·크기·아이콘 단서), 무섭거나 어두침침한 느낌 금지. 글자 대비 WCAG AA(4.5:1), 큰 글자 3:1, 터치 타깃 ≥ 44px, 레이아웃 이동 0(문서 높이·보드 크기·`--ui-h` 302px 불변).
- 외부 폰트·외부 이미지 의존 금지. CSS(그라데이션·그림자·`clip-path`·`mask`)와 **인라인 SVG/CSS 배경 데이터 URI 소량**은 허용하되 새 래스터 이미지는 만들지 않는다. 첫 방문 다운로드 증가 **+3% 이내**(용량을 보고에 적는다).

## 새 시안 D — "보석 세공 (Facet Crystal)" : 밝고 투명한 크리스털 (밝은 캔디 톤 유지)
컨셉: 게임의 보석처럼 **UI 면이 보석 세공면(facet)으로 깎인 듯** 보이게 한다. 밝은 하늘·정글 배경과 흰·라벤더 톤은 그대로 두고, 질감만 "유리·크리스털"로 바꾼다.
- **면**: 크림-라벤더 흰색(예: `#fbf9ff → #f2edff`) 위에 **아주 연한 대각선 면 분할**(예: `linear-gradient(115deg, rgba(255,255,255,.6) 0 36%, rgba(255,255,255,0) 36% 100%)`)로 유리 평면이 겹친 느낌. 큰 패널에는 한두 개의 **희미한 빛줄기(대각선 하이라이트 띠)**.
- **림(테두리)**: 사방이 같은 1.5px **그라데이션 림**(`background: <면> padding-box, linear-gradient(135deg, #fff, #cfc3ff 55%, #ffe39a) border-box` + 투명 테두리) — 좌상단이 밝고 우하단이 연한 보석색. 한쪽만 두꺼운 면은 없다.
- **선택칩**(난이도·탭): **세공된 보석**처럼 3개 면(위 밝음 / 중간 채도 / 아래 깊음, 하드 스톱 그라데이션) + 얇은 림 + 사방 빛무리. 선택되는 순간 **빛줄기가 한 번 지나감**(240~400ms, 한 번만).
- **주요 버튼([시작] 등)**: 앰버 보석 절단면(밝은 윗면·진한 아랫면의 그라데이션이지만 **밑면 띠 없음**), 림, 모서리에 4점 별빛(✦) 하나, 7초에 한 번 느리게 지나가는 광택(정지 가능). 눌림 = 밝기 ↑ + `scale(.98)`.
- **역할 색 = 보석 이름**: 힌트=에메랄드, 메뉴=자수정, 리셋=장미석영 — 면 분할·림 색만 달라지고 구조는 같다.
- **정보 줄·알약·HUD·랭킹 행**: 가장 조용하게 — 연한 유리 면 + 1px 림 + 환경 그림자 하나. 스테이지 카드: 클리어=에메랄드 면(✓·별 유지), 현재=앰버 보석 + 빛무리, 잠김=무광 라벤더(자물쇠 유지). 흐림(`backdrop-filter`)은 메뉴·패널의 큰 면에 가볍게(반경 ≤ 10px) 써도 좋지만 **뿌옇게 되면 쓰지 않는다**(글자 아래 면은 알파 ≥ .9).

## 새 시안 E — "원소 빛무리 (Elemental Aura)" : 깊은 유리 + 안에서 켜지는 빛 (보드와 같은 어두운 톤)
컨셉: **어둡고 깊은 인디고 유리 패널 + 요소(원소)색으로 켜지는 빛**. 이 게임의 보드는 이미 짙은 남색 트레이라, 흰 HUD가 어두운 보드 옆에 붙은 지금의 대비 불일치를 없애고 **메뉴·HUD·보드가 하나의 세계**로 보이게 한다. 밝은 정글 배경 위에 어두운 유리가 떠 있어 대비가 선명해진다. (예전 spec이 "귀여운 표정과 네온 톤 충돌"을 걱정했으니 **형광 네온이 아니라 부드러운 빛무리**로 한다.)
- **면**: 깊은 인디고 유리(예: `rgba(26, 22, 72, .74~.86)` + `backdrop-filter: blur(10px) saturate(1.3)`) — 위가 약간 밝은 세로 그라데이션, 바닥이 거칠어 보이지 않게 노이즈 없음. **글자는 흰색/연한 라벤더**(`#f6f4ff` / `#d6d0ff`, 대비 ≥ 4.5:1을 측정으로 확인).
- **림**: 사방 1px **빛 림** — 막대 전체는 여섯 원소색(불 `#ff5a64`·물 `#3f8cff`·풀 `#2fbf71`·번개 `#ffc21a`·어둠 `#9a5cf0`·빛 `#aeb6d8`)이 아주 은은하게 이어지는 그라데이션 림이고(채도·불투명도 낮게, 장식이 되지 않게), **선택된 칸 쪽의 림만 밝게** 켜진다.
- **선택칩**: **켜진 보석** — 면이 앰버(또는 해당 요소색)로 밝게 채워지고(글자는 진한 색, 대비 확인), 사방 부드러운 빛무리(`0 0 22px rgba(색,.5)`, 오프셋 없음) + 윗 하이라이트. 선택되는 순간 빛이 **켜지듯 퍼짐**(240ms).
- **주요 버튼**: 앰버 핵심색 + 사방 빛무리, **느리게 숨 쉬는 빛**(3.6초 주기, 움직임 줄이기에서 정지), 눌림 = 빛이 커지고 `scale(.97)`.
- **HUD**: 어두운 유리 바 + 빛나는 진행 막대(채움이 원소색, 값은 흰 글자). 타이머·점수·목표·게이지·미션 칩이 보드(`#17133f` 트레이)와 같은 톤으로 이어진다. 3개 버튼은 역할 색 림(민트·라벤더·핑크)의 어두운 유리 버튼.
- **카드·행**: 스테이지 카드 — 클리어=에메랄드 림 + 은은한 안쪽 빛(✓·별은 밝게), 현재=앰버 빛무리, 잠김=어둡고 흐린 유리 + 자물쇠. 명예의 전당: 어두운 유리 패널, 1·2·3위는 금·은·동 림 빛. 별은 노란 빛.
- 가독성·피로: 어두운 면이 눈을 피로하게 하거나 칙칙하지 않게 **채도 있는 색 포인트**를 충분히 쓰고, 글자 크기를 줄이지 않는다.

## B (플랫·유리) — 기존 시안 그대로
`css/ui-depth-B.css`와 이미 찍은 B 이미지를 그대로 쓴다(블러가 있는 원래 B). **뿌옇게 보인다는 사용자의 지적이 있었다는 점**은 비교표 설명에 적는다.

## 할 일
1. **D·E를 각각 `css/ui-depth-D.css`·`css/ui-depth-E.css`**로 만든다(1차와 같이 `style.css`/`edu.css` 뒤에 붙는 덮어쓰기, `!important` 0개, `:root` 접두어). 같은 토큰(`--dp-*`)을 정의하고 규칙 수를 센다.
2. **스스로 보고 고치는 반복(필수)**: 각 시안을 촬영해 **직접 화면을 보고** 어색한 점(뿌옇다·탁하다·무겁다·촌스럽다·장난감 같다·밋밋하다·글자가 안 읽힌다·위계가 없다)을 적고 고치는 일을 **시안마다 최소 3번** 반복한다. 모서리·글자 가장자리·림 색 이음매는 **확대 크롭**으로 확인한다. 최종 CSS에는 라운드별로 무엇을 고쳤는지 주석 한 줄씩.
3. **촬영**(PC 1280×720 우선, 같은 시드·같은 프로필·같은 저장 상태, 1차와 같은 하니스): 시작 / 레벨 선택 / 플레이 HUD / 명예의 전당 / 교육용 시작 / 교육용 문제 팝업 / 일시정지 / 결과(TIME UP) / 프로필 만들기. **비교표 2×2 = 현재 · B 플랫·유리 · D 보석 세공 · E 원소 빛무리**(라벨 그대로), 파일명 `ui-depth-compare4-{화면}-1280.png`. 폰 390×844는 시작·레벨 선택·플레이·명예의 전당만(1×4). 개별 이미지 `ui-depth-{화면}-{cur,B,D,E}-{1280,390}.png`.
4. **상태·순간 연출 시트**: 주요 버튼·난이도 막대(선택 전후)·스테이지 카드·보조 버튼에 대해 기본/올림/누름/포커스/비활성(`ui-depth-states4-*.png`), 그리고 **D의 빛줄기 지나감과 E의 켜지는 빛**을 시간 순서 3~4프레임 띠(0/80/160/320ms)로 한 장씩(`ui-depth-motion-{D,E}.png`) — 정적 이미지로 "재미 요소"가 전달되게. 움직임 줄이기 상태 한 장도.
5. **측정표**(현재·B·D·E): 글자 대비 최저·4.5 미만 수(E는 흰 글자 조합 포함 표본 확대), 경계(림)·선택 단서 2.0 미만 컨트롤 수, 터치 타깃 최소, 레이아웃 이동(0이어야 함), 그림자·글로우 층 수, `backdrop-filter` 요소 수·반경 최대, **받침 규칙 위반 검사**(블러 0 오프셋 그림자·`inset 0 -Npx 0`가 새 CSS에 0개인지 grep), CSS 크기(원본/gzip)와 첫 방문 다운로드 증가율, 프레임 시간(메뉴·플레이 화면, CPU 4배 감속·DPR 2 — 이 환경은 변별력이 약하다는 한계를 그대로 적는다).
6. **정직한 평가**: 각 시안의 강점·약점을 (a) 전문 디자이너 시선(위계·광원·절제·주제 일관성) (b) 학생·사용자의 재미와 눌러야 할 곳의 명확함 (c) 기존 게임(보드·정글 배경·로고·보석)과의 어울림 (d) 위험(E는 어두워 보임·D는 흰 면이 많아 밋밋함 등) 관점에서 적는다. 근거 없이 "고급스럽다"고 단정하지 말고, 무엇이 왜 그렇게 보이는지 요소로 설명한다. **권장안(이유 한 줄)**을 제시하되 선택은 사용자 몫이다.
