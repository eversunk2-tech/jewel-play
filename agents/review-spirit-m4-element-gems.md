## 검증할 것 (표로 판정)
1. **데이터·단계 수**: 특별 레벨 6곳의 정령(초보 번개/빛, 중수 풀/불, 고수 물/어둠), 이름 = 보석 이름 + " 정령", 단계 수 n(초보 3 / 중수·고수 SEQ 부분 수 3 또는 4 — 코드 표와 `CONFIG.stages.missions`를 대조), 특별이 아닌 레벨에는 정령 요소(DOM·상태·낭독)가 **전혀 없음**.
2. **규칙 불변 증명(네가 직접, 새 시드 `60,000,000~`)**: 기준선 `game.js`와 작업 트리 `game.js`로 **같은 시드·같은 행동**에서 판 단위로 같은지(≥ 300판, 난이도 3 × 레벨 {1,4,5,9,10} × 두 앱, 교육용은 보통·많이 두 모드): 점수·미션 카운터·`goalMet`·종료 시점·시간·게이지·`state.edu`·`Math.random` 호출 수·결과 문구(정령 줄 제외). 음성 대조(일부러 규칙을 바꾼 사본이 불일치로 잡히는지). 가짜 DOM 하네스는 직접 짜거나 이전 Review(`scratchpad/review-mission-m3/`)의 것을 복사해 **검토한 뒤** 쓴다.
3. **단계 k 계산**: 초보 `floor(점수 × n ÷ 목표)`의 경계(목표 1/3·2/3 직전/정확히/초과, 교육용 목표 ×1.2·모드 표 기준), 감소 없음(판 도중 점수가 줄지 않지만 보호 코드 확인), SEQ k = 끝난 단계 수, 한 행동에서 여러 단계가 동시에 끝날 때 낭독·효과음 **한 번**, 이중 낭독 없음(특별 미션 레벨에서 칩의 "미션 하나를 끝냈어요"와 정령 낭독이 겹치지 않음), 일반 레벨의 기존 낭독은 그대로. 교육용: 목표를 채웠는데 학습이 모자란 "거의 깨어났어요" 상태 → 학습을 채우는 순간 `stageDone()`·"깨어났어요! 고마워요"·효과음 한 번, 시간 초과 실패의 결과 줄.
4. **두 앱 동일성**: `spiritOf`·`spiritStep`·`SPIRIT_TEXT` 소스가 두 앱에서 주석 제거 후 글자 그대로 같은지(스크립트), 두 앱 `style.css` `cmp` 동일, 교육용 `[EDU]` 표식이 없는 곳이 일반용과 어긋나지 않는지(`diff`로 [EDU] 아닌 hunk 점검), 교육용 `game.js`가 M3 직후 `[EDU]` 블록(`guardGapOf`·`CONFIG.edu.many`·학습 칩)을 해치지 않았는지.
5. **화면(로컬 서버 + 별도 사용자 폴더의 헤드리스 Chrome, 모든 호출 `tabId` 명시, 배포 주소·기존 탭 금지)**:
   - 특별 레벨 6곳 × 상태 3(잠든 0 / 중간 / 완전히 깬) × 두 앱 + 교육용 학습 칩 포함 장면의 스크린샷. 정령이 **잠든 상태로 읽히는지**(흑백 + "zZ" + "깨어남 k/n" 글자), 칸이 색 외에 모양으로 구분되는지(색약), 중간 단계의 필터가 단계 수에 비례하는지.
   - 패널 높이 **≤ 93px**(SEQ 칩 포함)와 그때 보드 한 변이 "미션 칩 2개" 레벨과 같은지, 교육용은 "패널 + 학습 칩"이 기존 "미션 칩 2개 + 학습 칩"보다 높지 않은지 — 해상도 320×568·360×640·375×667·390×844·412×915·740×360·844×390·768×1024·1180×820·1280×800에서 **네가 다시 측정**(보드 한 변 px 표). 가로 넘침 0, 게이지 줄·[리셋] 단추가 화면 안.
   - 글자 대비는 **렌더링된 색으로 측정**(WCAG 4.5:1) — 패널 제목·"깨어남 k/n"·"zZ"·결과 줄·"깨운 정령" 줄(잠든 정령의 흑백·반투명 위 글자 포함).
   - `prefers-reduced-motion: reduce`에서 전환·번짐·"zZ" 애니메이션 없음, 무한 애니메이션 화면당 ≤ 3, 콘솔 오류 0, 애니메이션 중 붉은 점멸·흔들림·확대 "피격" 느낌 없음(키프레임을 읽고 정지 프레임도 확인).
   - 결과 화면(클리어·실패), 레벨 선택의 "깨운 정령 n/6"(0·일부·6/6)과 작은 정령 6개의 컬러/흑백, 설명판 문구, 카드 `aria-label` 형식(초보에는 "특별 레벨"·미션·쉬어가기 말이 없음, 중수·고수는 "특별 레벨, 잠든 ○ 정령, …"), **카드의 보이는 모양이 변경 전과 같은지**(카드 DOM·CSS 비교).
   - 스크린샷은 `review-spirit-m4/shots/`에만. 끝나면 서버·탭·프로세스 정리.
6. **접근성**: 패널의 읽히는 이름·`aria-hidden` 장식·`role="status"`(polite) 낭독 문구, 칩 `role="progressbar"`·`aria-valuenow/max` 유지, 키보드로 게임 흐름이 달라지지 않음(포커스 이동 불변), 화면 읽기 프로그램은 **확인하지 못함**으로 적고 마크업 근거만.
7. **비폭력·문구(초등학생이 읽는 쉬운 말)**: 새 사용자 노출 문자열 **전부 출력**(패널·낭독·결과 줄·설명판·카드 aria·"깨운 정령"·교육용 학습 칩/설명판/알림)해 눈으로 확인하고, spec §27.6.2의 "피하는 말"(보스·적·몬스터·전투·싸움·대결·공격·때리다·쓰러뜨리다·처치·무찌르다·물리치다·체력·HP·데미지·피해·죽다·사망·KO·파괴·부수다·폭발시키다·패배·졌다)과 "쉬어가기"·"쉬어", 어려운 말·틀린 숫자·외부 링크·과금·도박이 없는지 **저장소 전체 정규식 검사**(새 파일·새 hunk 대상)로도 확인. "깨우기"가 귀찮게 하는 느낌으로 읽히지 않는지에 대한 의견(어린이 반응은 **확인하지 못함**).
8. **저장·서버 무변경**: `save` 키 목록·`buildSnapshot` 결과가 기준선과 같은지(같은 저장 입력 여러 개), 저장 JSON에 정령 관련 새 키 없음, `git diff -- apps/element-gems/server apps/element-gems/ranking*.js apps/element-gems-edu/ranking*.js nickname.js edu-data assets`가 비어 있는지(새 이미지·음원·글꼴 **0개**), "깨운 정령 n/6"이 `save.stages` 기준 계산인지(별 있는 칸만, 세 난이도 합, 현재 난이도와 무관), 옛 저장·빈 저장·손상된 저장에서 0/6로 안전한지.
9. **시험 직접 실행(Node 24는 글롭)**: 일반용 `node --test apps/element-gems/test/*.test.js`(M4-A 보고 기준값), 서버 `node --test apps/element-gems/server/test/*.test.js`(**65**), 교육용 `node --test apps/element-gems-edu/test/*.test.js`(M4-B 보고 기준값). `git diff`로 기존 시험이 앵커·기대값·setup만 바뀌고 **단언 삭제·약화가 없는지 한 줄씩**(특히 `style.css` "맨 끝" 앵커 시험이 앵커만 옮겨졌는지).
10. **변이 시험**: 신규 `spirit.test.js`(두 앱)가 실제로 잡는지 **새로 고른 곳 최소 16곳**(예: 정령 색 표 한 칸, `easySteps`, `floor`→`round`, k 감소 허용, 이중 낭독 허용, 마지막 단계 효과음 누락, 결과 줄 문구 바꿈, 깨운 정령 계산에서 `stars > 0`→`>= 0`, 세 난이도 합→현재 난이도만, 교육용 칩 이름 분기 제거, "거의 깨어났어요" 분기 제거, `stageDone` 대신 `goalMet`, reduced-motion 규칙 삭제, `aria-hidden` 제거, 특별이 아닌 레벨에 패널 표시, 초보 카드에 "특별 레벨" 추가, 금지어 하나 추가 등)으로 확인하고, 잡지 못하는 곳은 "시험 구멍"으로 적는다.
11. **변경 범위**: `git status`·`git diff --stat`으로 변경 파일이 대상뿐인지, 새 파일이 두 `spirit.test.js`뿐인지, `index.html` 정적 자리표시자에 옛 값이 없는지, 일반용에 ?·문제 요소(`EduQuiz`·`#learn`)가 없는지.
