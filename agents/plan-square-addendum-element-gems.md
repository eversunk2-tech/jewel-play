# Plan 추가 지침 — 2×2 정사각형 매치 규칙 (난이도 Plan에 합류)

## 배경
사용자가 추가 요청했다: **"같은 보석 4개가 정사각형(2×2) 형태로 모였을 때도 보석 클리어가 되도록 해줘."**
이 규칙은 매치 판정·유효한 수 판단·힌트·초기 보드·재섞기·점수/게이지/시간 보너스에 영향을 준다. 난이도 수치(§15)를 시뮬레이션으로 보정할 때 **이 규칙이 켜진 상태**로 보정해야 하므로, 이미 진행 중인 난이도 Plan 작업에 합친다.

## 규칙 초안 (이대로 시작하되 문제가 있으면 근거와 함께 수정 제안)
1. **정사각형 매치**: 같은 종류 보석이 2×2 칸을 이루면 매치로 판정한다. (기존 가로/세로 3연속 매치와 **함께** 판정, 둘 중 하나라도 성립하면 제거)
2. **그룹화**: 가로/세로 3연속과 2×2는 "같은 종류의 연결된 매치 칸의 합집합"을 한 그룹으로 본다(기존 L/T/십자 규칙과 동일). 그룹 크기 = 합집합 칸 수. 따라서 단독 2×2는 크기 4 그룹이다.
3. **점수·게이지·시간 보너스**: 별도 보너스를 새로 만들지 말고 기존 그룹 크기 규칙을 그대로 적용한다(4개 = 점수 100, 게이지 +5, 시간 보너스 4개 값). 보상 증가가 필요하면 열린 질문으로만 제안한다.
4. **유효한 스왑**: 스왑 결과로 3연속 **또는 2×2가 생기면** 유효. `hasValidMove` / `listMoves` / 힌트 탐색(`findHint`)에 2×2를 반영한다. 무효 스왑은 기존대로 되돌림.
5. **초기 보드 / 재섞기 / 리필**: 초기 보드와 재섞기 결과에 **2×2 정사각형이 없어야** 한다(자동 제거 방지) + 3연속도 없어야 하며 유효한 수 ≥ 1. 리필로 생기는 정사각형은 연쇄로 허용(기존 연쇄 규칙과 동일).
6. **연쇄·칭찬 팝업**: 기존 연쇄 단계·배율 규칙 그대로. 칭찬 조건 "4매치"에 2×2도 포함된다.
7. **스킬 제거와의 관계**: 변경 없음(스킬로 제거된 칸은 매치 판정 대상이 아님. 스킬 후 낙하/리필 뒤 자동 매치에는 2×2도 포함).
8. **시각 피드백(선택 제안)**: 정사각형으로 터질 때 일반 매치와 구분되는 짧은 연출(예: 4칸 중심에 별 모양 반짝임) 정도만 제안. 범위가 커지면 "2차"로 분리.

## §16에 포함할 항목
1. 규칙 정의(위 초안을 확정형으로), 경계 사례 표: 단독 2×2 / 2×2+가로 3연속이 겹치는 L·T 유사형 / 3×3 같은 색 블록(전부 한 그룹, 크기 9) / 서로 다른 색 인접 / 보드 가장자리·모서리 / 연쇄 중 동시 발생
2. **알고리즘 영향 범위**(함수 단위: `findMatches`, 초기 보드 생성, 재섞기, `hasValidMove`, `listMoves`, 힌트, 점수·게이지 계산 입력 형태)와 **의사코드**(2×2 검출은 모든 (r,c)에서 4칸 동일 종류 검사 후 마킹)
3. **밸런스 영향**: 2×2 허용 시 매치 빈도가 늘어 게이지/시간/점수가 빨라지는 정도를 **시뮬레이션으로 측정**(2×2 규칙 on/off 비교 표: 한 판 매치 수, 스킬 사용 횟수, 판 길이). §15의 난이도별 수치는 **규칙 on 기준으로 보정**한다. 보정이 필요하면 §15 표와 §16이 서로 모순되지 않게 한다.
4. 구현 영향 범위와 단계 분해(Build용), 검증 체크리스트(Review용: 단독 2×2 제거, 겹침 그룹 크기, 가장자리, 초기 보드 무정사각형 500회, 재섞기 후 무정사각형, 힌트가 2×2 수를 제안, 무효 스왑 되돌림, 연쇄 중 2×2)
5. 열린 질문(최대 3개)
