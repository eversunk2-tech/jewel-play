# Plan 지침 5차 — B-1 대 "B-1 + 비친 한 스푼" 2자 비교 (3·4차 지침의 후속, 범위 축소)

작성: 2026-11-20 (메인 세션). 모델: Sonnet. **1~4차 지침의 안전 규칙(브라우저 `tabId`·로컬 서버만·`apps/` 수정 금지·커밋/푸시/서버 명령 금지·다른 세션의 Chrome 접촉 금지)·산출물 위치(`PD` = scratchpad `plan-ui-depth/`)·촬영 하니스·측정 방법은 그대로 유효하다.** 이번에는 **비교 대상이 2개뿐**이다.

## 사용자 요청 (2026-11-20, 그대로)
*"b-1과 b-1(비친 한스푼) 두개만 좀더 새로 비교해서 제시해줘"*
→ 비교 대상: **① B-1 "맑은 유리"(지금 완성본, `PD/css/ui-depth-BG.css` — 한 글자도 바꾸지 않는다) ② B-1S "B-1 + 비친 한 스푼"(이번에 새로 다듬는 안)**. B 원래·B-2·D·E는 이번 비교에서 뺀다(기존 파일·이미지는 그대로 둔다). "새로" 비교하라는 뜻이므로 **지난번 실험(큰 패널 3곳만 알파 .93, 블러 없음 → 구름 윤곽·잎 무늬가 얼룩으로 비쳐 뿌옇게 보여 버림)을 그대로 재촬영하지 말고, 얼룩 없이 "비침 한 스푼"이 되도록 값을 다시 찾는다.**

## 목표
"비침 한 스푼"의 정의: **풍경 색이 면 뒤에서 은은히 스미되, ① 얼룩(구름 윤곽·잎 무늬가 또렷이 비침) 없음 ② 회색 안개(뿌옇다) 없음 ③ 글자 대비 4.5:1 유지**. 사용자가 B 원래에서 "뿌옇다"를 지적했으므로 **B 원래의 탁함이 돌아오면 실패**다. 사용자는 이전에 "흐림 효과 금지 이유가 성능뿐이었다면 흐림을 써도 좋다"고 했다(2026-11-20). 따라서 **B-1S에 한해 `backdrop-filter`를 약하게 쓰는 것을 허용**한다(아래 값 탐색 범위, 상한 있음).

## 값 탐색 (scratchpad에서만, 최종 1안을 고른다)
- **탐색 범위**: 면 알파 .88~.96 / 블러 0·4·6·8px / 채도(`saturate`) 1.0~1.4 / 밝기(`brightness`) 1.0~1.08 / 면 색조(연보라·연하늘·크림 — 회색기 없는 색, 기존 B-1 면 색 계열). 블러는 **8px 이하**, `backdrop-filter` 요소는 **화면당 8개 이하**, **플레이 중 HUD·보드에는 쓰지 않는다**(구름이 움직여 매 프레임 다시 흐려짐 + 가독성). 교육용 문제 팝업·일시정지·결과처럼 **어두운 막 위에 뜨는 패널에는 효과가 거의 없으므로 B-1과 같게** 둔다(스푼 대상 아님).
- **스푼 대상 후보**(어느 범위까지가 좋은지도 판단해 보고): ⓐ 큰 패널(레벨 설명판·명예의 전당 패널) ⓑ 시작 화면의 난이도 막대·안내줄·프로필 알약·상단 우측 [명예의 전당] ⓒ 레벨 선택 상단 알약(클리어·깨운 정령)·[뒤로]. **누르는 것(선택칩·주요 버튼·카드)과 글이 많은 면은 불투명 그대로**(비침 없음). 효과 수는 B-1과 같게(면 + 링 + 확산 그림자 + 큰 패널 반사광 1개).
- **고르는 기준(수치로 적는다)**: ① **얼룩 지수** — 면 안쪽(글자·아이콘 제외)의 고주파 에너지(예: 라플라시안 분산 또는 3×3 평균과의 차)를 같은 영역의 **배경 단독 촬영**(UI 숨김)의 값과 비교해 낮을수록 좋음. 목표: 지난번 스푼(알파 .93·블러 0)보다 **절반 이하**. ② **회색 안개 지수** — 면 안쪽 평균 채도(HSV S)와 면 색 자체의 채도 차이, 그리고 면 주변 배경 대비 면 안쪽 평균 밝기 상승량(희뿌연 정도); B 원래(번짐 10.5%)보다 **분명히 낮고** B-1(0%)과의 차이가 눈으로 "비침"으로 읽히되 "탁함"으로 읽히지 않아야 함. ③ **최악 배경 대비** — 각 스푼 면의 글자에 대해, 화면의 **가장 어둡고 채도 높은 배경 위치**(배경 단독 촬영에서 해당 면 아래 영역의 최소 밝기)를 가정해 계산한 글자 대비가 4.5:1 이상(구름이 움직여 배경이 바뀌므로 **구름 위치 3시점**에서 각각 측정). ④ 크롭을 눈으로 봐서 **얼룩·안개·거침**이 없는지 스스로 비판(라운드 ≥ 3, 확대 크롭으로, 어색한 곳을 적고 고친다).
- 탐색에서 **얼룩이나 안개 없이 비침이 읽히는 조합이 없으면 그대로 "B-1S는 만들 수 없다(이유·증거 이미지)"고 정직하게 보고**한다(억지로 만들지 않는다). 이 경우에도 마지막으로 시도한 가장 좋은 값 1안을 보여 주되 "채택 권장하지 않음"으로 적는다.

## 구현 형태
- **B-1 파일(`ui-depth-BG.css`)은 변경 금지.** B-1S는 **`PD/css/ui-depth-BGS2.css`(덮어쓰기 조각)**로, BG.css 뒤에 붙이는 **작은 오버레이**(스푼 대상 선택자의 면·알파·블러·`@supports` 폴백만 바꿈)로 만든다 → "스푼은 켜고 끄는 한 덩어리"임이 코드로 보이게. 선언 규칙은 3차와 동일(`:root` 접두어, `!important` 0, 테두리 두께 불변·색만 변경, 받침 없음, 레이아웃 이동 0).
- **폴백**: `@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px)))` → 알파 .97 불투명으로(B-1과 거의 같게). `@media (prefers-contrast: more)`에서도 불투명으로. `-webkit-backdrop-filter` 접두어 포함.
- **중첩 금지**: `backdrop-filter`를 가진 면 안의 자식에 또 `backdrop-filter`를 쓰지 않는다(브라우저가 뒤 배경을 못 본다). 스푼 면 안의 알약·버튼은 불투명.
- **옛 실험 파일 `ui-depth-BGS.css`**는 건드리지 않고 기록으로 둔다.

## spec §49 초안 갱신 (`PD/spec-49-draft.md`)
49.0에 사용자 요청 5("b-1과 b-1(비친 한스푼) 두개만 좀더 새로 비교")를 인용하고, 49.2에 **B-1S 값표·적용 범위(선택자 목록)**, 49.3에 새 측정·정직한 평가·권장을 추가하며, 49.4 결정에 **"B-1 / B-1S 선택(권장안 먼저)", "스푼 적용 범위", "흐림 사용 시 CLAUDE.md 문구(흐림 금지 해제 반영 여부 — 지금은 안 고침)"**를 넣는다. 흐림을 쓰므로 **B-1S를 채택하면 49.0의 "흐림 금지 해제(사용자 결정 2026-11-20)"가 실제로 적용된다**는 점을 명시한다. spec.md에는 붙이지 않는다(승인 전).
