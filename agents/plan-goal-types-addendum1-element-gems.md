# 추가 지침 1 — 사용자 조정(2026-11-08): 초보만 점수 목표, 교육용은 학습 1순위 (이전 지침의 일부를 **대체**)

원 지침: `agents/plan-goal-types-element-gems.md`. 사용자가 방금 요구를 구체화했다. 충돌하면 **이 문서가 우선**이다. 이미 쓴 내용은 필요한 만큼 고친다(§27은 네가 쓰는 §이니 고쳐도 된다, §1~§26은 수정 금지).

## 사용자 말(요지, 원문 취지)
"E 방안으로 바꾸면 초보 외에 중수와 고수는 목표 점수를 가지고 도전하는 것이 아니니까, **초보의 경우 1단계 점수를 4000에서 시작**하는 것으로 하고, **학습상자 출현이 많아 학습도 많이 이루어지게(점수도 많이 올라감)** 하고 **스킬도 원래처럼 사용**하는 것으로 해줘. **게임의 흐름은 중간중간 좀 끊겨도 교육용 버전은 학습이 1순위이니 괜찮다.** **중수와 고수 단계에서도 각각 단계별 미션이 다르지만, 학습상자 출현과 문제 풀기가 마찬가지로 기존보다 더 많이 일어나도록** 해줘."

## 대체되는 것
1. 원 지침 요구 2의 "초보에서도 스킬 사용 미션" → **폐기**. **스킬은 원래 규칙 그대로** 쓴다(스킬 규칙·게이지·위력 변경 없음). 초보에 스킬 사용 전용 미션을 새로 넣지 않는다. (중수·고수 미션 카탈로그에 스킬 관련 미션을 둘지는 네가 근거와 함께 제안하되 **필수 조건이 되지 않게**.)
2. 원 지침 5번의 "정답 보너스를 문제 수에 반비례로 낮추기" → **사용자 의도와 다르므로 폐기**. 사용자는 **문제가 많아져 점수도 많이 올라가는 것을 원한다**(학습 보상 = 점수). 다만 "점수 격차가 학습 격차로 이어져 학습이 약한 학생이 막히는 위험"은 **위험·한계로 적고** 완화책(예: 보너스 상한·진행 보조·미션형 난이도에서는 점수가 목표가 아님)을 제안한다.
3. "수업 흐름이 끊기지 않게" 같은 **흐름 우선 기준은 교육용에서 완화**한다(질문 간격 보장 등은 최소한만). 교육용은 **학습이 1순위**다. 일반용에는 선물상자·문제가 없다.

## 확정된 설계 조건
- **목표 점수는 초보에만** 남는다. **중수·고수는 점수 목표가 아니라 레벨별로 다른 미션**(원소 수집·연쇄·큰 매치·스킬 사용·시간 보너스 등)으로 도전한다. 별은 계속 **남은 시간 기준**(서버 변경 없음).
- **초보 1단계 목표 점수 = 4000에서 시작**(레벨 증가 모양은 기존 곡선 방식). 이 4000이 **일반용 값인지 교육용 화면에 보이는 값인지**는 계획서가 열린 질문으로 올리고 **권장안**을 정한다(현재 교육용은 일반용×1.2, 초보 1단계 일반용 3500 → 교육용 4200). 교육용의 문제 보너스가 점수를 많이 올리는 점을 반영해 **초보 10레벨 전체 표(일반용·교육용)** 를 시뮬레이션으로 보정한다.
- **교육용: 선물상자(?) 출현을 크게 늘리고**(한 레벨 평균 문제 수 목표를 근거와 함께: 예 6~10개) 정답 보너스로 점수가 눈에 띄게 오르게 한다. **중수·고수 미션 레벨에서도** 선물상자·문제 풀이를 기존(한 레벨 약 2.6~4.0개)보다 **더 많이**.
- **게임 흐름이 자주 끊겨도 괜찮다**(교육용 한정). 다만 어린이가 지치지 않게 하는 최소 장치는 제안(예: 질문 연속 방지 최소 간격, 수업 시간 모델).

## 반드시 다룰 핵심 쟁점
1. **보너스가 크면 점수 목표를 일찍 넘겨 레벨이 짧아지고 문제 수가 오히려 줄 수 있다**(이미 측정: 새 낮은 목표에서 초보 한 레벨 문제 2.6~3.9개로 이전 2.9~5.1개보다 줄었다). 사용자가 원하는 "문제가 많이 일어나는 것"을 **보장하는 설계**를 비교하고 권장안을 정한다: ① 교육용 클리어 조건에 "선물상자 문제 N개 풀기"(맞든 틀리든 푼 개수 또는 맞힌 개수)를 **학습 미션**으로 포함 ② 문제 수 하한을 보장하는 ? 스폰 규칙 ③ 보너스를 포함한 점수 목표 재산정. 초보의 점수 목표 4000대와 교육용 보너스(240/300/390)를 결합했을 때 **레벨당 문제 수·클리어율·클리어 시간**을 시뮬레이션해 표로.
2. **중수·고수 미션 레벨의 학습 미션**: 레벨마다 다른 원소 미션에 더해 "선물상자 문제 N개 풀기/맞히기" 같은 **학습 조건**을 어떻게 결합할지(난이도별 N, 단원별 문제 풀 소진, 같은 문제 반복 규칙과의 관계). 문제가 많이 나와도 **문제 풀(소단원 60문제, 한 바퀴를 다 돌기 전에는 같은 문제 금지)** 이 감당하는지(한 레벨 N개 × 레벨 수 × 반복)를 계산해 적는다.
3. **일반용 vs 교육용**: 일반용에는 ?·문제가 없으므로 일반용의 초보·중수·고수 목표 구조(점수·미션)는 학습 요소 없이 같은 미션 구조를 쓰되 값을 어떻게 둘지 정한다(교육용 전용 학습 미션은 일반용에서 제외).
4. **비폭력 특별 레벨(보스류)** 조사·제안은 원 지침 4번 그대로 진행(사용자가 이 조사를 요청했다).
