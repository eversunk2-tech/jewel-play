# Plan 지침 — 교육용 문제 "지엽적 문제" 찾아내기 (분석만, 파일 수정 없음)

작성: 2026-11-10 (메인 세션). 모델: Sonnet. **분석만 한다 — 프로젝트 파일을 고치지 않고, 커밋·푸시도 하지 않는다.**

## 배경
교육용(`apps/element-gems-edu/`)의 사회 2학기 3~6학년 25개 소단원 × 60문제(OX 24 + 객관식 36)를 사용자가 점검했더니, 교육과정상 의미가 작은 **지엽적인 문제**가 있다고 한다. 대표 예(6학년 2학기 "세계 여러 지역의 지형 경관"):

- "황토가 섞여 누런색을 띠고 굽이쳐 흐르는 강은 어디일까요? (아마존강/나일강/콩고강/황허강)" → 황허강
- "가파른 산 사이에 좁고 긴 해안선이 이어지는 곳은? (…/송네 피오르/…)" → 송네 피오르
- "넓은 모래사장이 펼쳐진 해안 경관의 예는? (펀디만/포트 캠벨 국립 공원/엘 아르코/마케나)" → 마케나

사용자의 설명: "구체적인 **지명 등**(교과서 사례로 나온 작은 지역·시설·이름)을 보기에서 **고르게 하는** 문제는 교육과정상 의미가 없다. 소스 학습지에 그 내용이 있기는 하다." 사용자는 이런 문제를 **OX 문제로 바꾸기**로 정했다(이름을 문장에 주고 "맞다/틀리다"만 판단하게). 이 지침의 일은 **어떤 문제가 해당하는지 빠짐없이 찾아 목록으로 만드는 것**이다. 고치는 일은 다음 단계라 하지 않는다.

## 입력과 출력 (모두 세션 scratchpad, 프로젝트 폴더에는 아무것도 만들지 않는다)
- 입력(소단원별 한 파일): `/private/tmp/claude-501/-Users-sungchul-Desktop-play2-jewel-play/a531f417-6e12-4899-8faf-38c202023dbb/scratchpad/qreview/in/<소단원id>.txt`
  - 형식: `FACT F01 …`(그 소단원의 사실 목록) 뒤에 문제가 한 줄씩. `번호 [ox|mc] 질문 (보기 / 보기 / …) → 정답 {사실ID}`. OX의 정답은 O 또는 X.
- 출력(소단원별 한 파일): `…/scratchpad/qreview/out/<소단원id>.json` (UTF-8 JSON, 형식은 아래)
- 끝나면 최종 보고는 **짧게**(소단원별 A·B 개수 표 한 개와 특이사항 3줄 이내). 자세한 목록은 파일에 넣는다.

## 무엇이 "지엽적"인가 (판정 기준)
**검사 대상은 객관식(mc)이다.** 보기(선택지) 중에서 **구체적인 고유명사를 골라야** 풀리고, 그 고유명사가 교육과정의 핵심 성취기준이 아니라 **교과서의 사례·사진·예시**로 나온 것이면 지엽적이다. OX 문제는 이미 이름이 문장에 주어져 있으므로 대상이 아니다(OX는 건드리지 않는다).

### 등급
- **A (확실히 지엽적)**: 정답(또는 보기 대부분)이 교과서 사례로 나온 **작은 지역·강·산·해안·시설·마을·행사·기관·인물·유물 사례의 이름**이고, 그 이름을 외워야만 풀린다. 개념·원리를 이해해도 풀리지 않는다. 예: 송네 피오르, 마케나, 펀디만, 호스슈 벤드 계곡, 짜오프라야강 수상 시장, 포트 캠벨 국립 공원, 지역 사례의 구체 도시·마을 이름, 특정 축제·박물관 이름.
- **B (애매)**: 고유명사를 고르지만 교육과정에서도 비교적 알려진 **핵심 지식**일 수 있다. 예: 대륙·대양 이름, 널리 알려진 큰 사막(사하라)·큰 산맥(히말라야·알프스)·큰 강(나일·아마존), 우리나라 주요 도시·강·산, 한국사의 핵심 인물·사건·유물(세종대왕, 훈민정음, 3·1 운동, 6·25 전쟁, 고인돌 등). 확신이 서지 않으면 A가 아니라 **B**로 둔다. 사용자가 최종으로 가른다.
- **해당 없음**: 개념·원리·특징·원인·결과·순서·분류·용어 풀이를 묻는 문제(예: "산지에서 계단식 농사를 짓는 까닭", "가장 먼저 할 일"). 고유명사가 **보기에 섞여 있어도** 고르는 힘이 "개념 이해"이면 해당 없음.
- 번호만 보는 오답 방지: "알맞지 않은 것은?"처럼 보기 하나하나가 이름인 경우, 정답이 이름 하나를 고르는 형태면 같은 기준으로 판정한다.

### 판정 보조 질문
1. 정답을 틀린 학생이 "그 지명을 몰라서" 틀리는가, "원리를 몰라서" 틀리는가? → 전자면 A/B 후보.
2. 같은 사실을 "이름 없이 특징만"으로도 물을 수 있는가? (물을 수 있다면 이름 고르기는 지엽적)
3. 그 이름이 해당 학년 교육과정 성취기준의 필수 용어(예: 지형 경관, 시장경제, 무역)인가? 필수 용어면 해당 없음.

### 유형 태그 (한 개 선택)
`지명`(지역·강·산·바다·국가·도시) / `인명` / `기관·시설` / `유물·작품` / `행사·사건` / `수치·연도` / `기타`

## 출력 JSON 형식
```json
{
  "unit": "soc-6-2-1-1",
  "counts": { "ox": 24, "mc": 36, "A": 0, "B": 0 },
  "flagged": [
    { "n": 28, "level": "A", "tag": "지명", "q": "질문 전체", "choices": ["…","…","…","…"], "answer": "정답 보기", "fact": "F04", "reason": "한 문장(왜 지엽적인지)" }
  ],
  "notes": "소단원 전체에 대한 한 줄 메모(예: 사례 이름 중심 단원이라 A가 많음). 없으면 빈 문자열"
}
```
- `q`·`choices`·`answer`는 입력 파일의 글을 **그대로** 옮긴다(고치지 않는다).
- 번호 `n`은 입력 파일의 번호와 같아야 한다. 해당 없음 문제는 넣지 않는다.
- 모든 mc 36문제를 **전부 읽고** 판정한다. 건너뛰거나 샘플만 보지 않는다. 읽은 mc 개수를 `counts.mc`에 적는다(36이 아니면 이유를 notes에).

## 하지 않을 것

- 사실 오류를 고치는 일(발견하면 notes에 한 줄로만 적는다).
- 문제를 새로 쓰거나 OX로 바꾸는 일(다음 단계).
