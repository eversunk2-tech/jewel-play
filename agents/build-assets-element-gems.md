## 1. 보석을 3D 이미지로 교체
- 기존 SVG 보석(`<symbol>`/인라인 SVG)을 `assets/gems/*.webp` 이미지로 교체한다. 칸 안에서 보석은 칸의 약 86% 크기, 중앙 정렬. `draggable="false"`, `pointer-events: none`(입력은 칸/보드에서 받음).
- 입체감 강화: `filter: drop-shadow(0 3px 3px rgba(0,0,0,.35))`, 선택 시 `scale(1.1)` + 밝은 글로우, 힌트는 부드러운 펄스, 제거 시 `scale` 확대 + `brightness` 상승 후 페이드(반짝이는 터짐).
- 게이지 버튼의 아이콘도 같은 보석 이미지를 사용한다. 색약 대응(모양 구분)은 이미지 자체의 모양 차이로 유지된다.
- 이미지는 시작 시 **미리 로드**(`new Image()` + `decode()`)해서 첫 판에 깜빡임이 없게 한다. 로드 실패 시 기존 SVG/색 도형으로 **폴백**(게임이 멈추면 안 됨).

## 2. 배경·HUD·보드 스타일 (참고: 레퍼런스 = Bejeweled 3 Lightning 화면)
- `body`(또는 앱 루트) 배경에 `bg-jungle.webp`를 `cover`/`center`로. 어두운 비네팅을 살짝 얹어 UI 가독성 확보.
- **보드**: 반투명 어두운 유리 패널 + 체크무늬(칸마다 교차로 `rgba(0,0,0,.18)`/`rgba(255,255,255,.06)`) + 금색 그라디언트 테두리와 안쪽 그림자. 모서리 둥글게.
- **HUD**(타이머 바, 점수, 배율, 버튼, 게이지): 금색 테두리의 장식 패널, 광택 있는 유리 버튼(핑크/보라 그라디언트 + 하이라이트)으로 레퍼런스의 캐주얼 보석게임 느낌을 낸다. 텍스트는 굵고 외곽선/그림자로 또렷하게.
- 시작 화면: `title-logo.webp`를 큰 제목으로(등장 시 살짝 바운스). 종료 화면: 로고 작게.
- 모바일 세로/가로/iframe 대응은 기존 반응형 규칙을 유지하고, 이미지가 레이아웃을 밀어내지 않게 크기를 고정(`aspect-ratio`/`max-width`).

## 3. 효과음: WebAudio 합성 → 샘플(WAV) 재생
- 기존 WebAudio 합성 코드를 **샘플 재생으로 교체**한다. `file://`에서 `fetch`가 막히므로 `HTMLAudioElement`를 쓴다. 효과음마다 `Audio` 객체 2~3개 풀을 만들어 겹쳐 재생(`currentTime = 0; play()`), 재생 실패(`play()` rejection)는 조용히 무시.
- 첫 사용자 입력(시작 버튼 탭)에서 오디오를 "잠금 해제"(모바일 정책)하고 이후 재생.
- 소리 토글(기본 ON)은 **효과음 + 배경음악 모두**에 적용, `localStorage`(`muted`)에 저장(기존 키 유지).
- 이벤트 ↔ 파일 매핑:

| 이벤트 | 파일 |
|---|---|
| 버튼 클릭 | `click` |
| 보석 선택 | `select` |
| 유효 스왑 | `swap` |
| 무효 스왑 | `invalid` |
| 매치/연쇄 단계 n | `match1`~`match5` (n≥5는 `match5`) |
| 게이지 가득 참 | `gauge-full` |
| 스킬 발동(컷인 시작) | `skill-fire`, `skill-water`, `skill-grass`, `skill-lightning`, `skill-dark`, `skill-light` |
| 칭찬 팝업 | `praise-good`, `praise-great`, `praise-awesome`, `praise-excellent` |
| 카운트다운 3-2-1 / GO | `countdown` / `go` |
| 남은 시간 10초 이하 매초 | `warning` |
| 시간 종료 | `timeup` |
| 최고 점수 갱신 | `newbest` |
| NO MOVES 재섞기 | `shuffle` |

- **배경음악**: `assets/music/bgm.mp3`를 `loop = true`, 음량 0.35. GO 이후 재생 시작, 일시정지/탭 숨김/종료 화면에서 정지(일시정지는 `pause()`, 재개는 `play()`), 다시 시작하면 처음부터. 스킬 컷인 중에는 음량을 0.15로 낮췄다가(덕킹) 복귀.

## 4. 스킬 컷인(캐릭터 등장) 연출 — 핵심 신규 기능
스킬 발동 시 해당 원소의 캐릭터가 화면에 크게 등장해 말풍선으로 기술 이름을 외치고, 사라진 뒤 공격 효과가 터진다. (요청: "그런 류의 게임들"의 필살기 컷인처럼 박진감 있게)

### 4-1. 흐름
1. 가득 찬 게이지 버튼 탭 → (불·풀은 대상 칸 선택 후) **컷인 시작**. 입력 잠금.
2. 컷인(총 약 1300ms): 아래 연출 재생 + `skill-*` 효과음.
3. 컷인 종료 → **스킬 효과 실행**(기존 로직: 제거·점수·연쇄·시간정지 등) + 강화된 공격 이펙트(4-4).
- 컷인 중에는 **게임 타이머와 정지/배율 타이머를 일시정지**한다(플레이어 손해 없음). 컷인 끝나면 재개.
- 컷인 중 화면 아무 곳이나 탭하면 **건너뛰기**(남은 연출을 즉시 종료 후 효과 실행).
- 메뉴(소리 토글 옆)에 **"컷인 연출" ON/OFF 토글**(기본 ON, `localStorage`에 `cutin` 저장). OFF면 텍스트 배너(스킬 이름 팝업)만 0.5초 표시 후 바로 효과 실행.
- `prefers-reduced-motion`이면 흔들림/회전선 없이 페이드 위주 600ms 짧은 버전.

### 4-2. 컷인 레이어(`#cutin`, 화면 전체, `position: fixed`, 최상단 z-index, `pointer-events`는 건너뛰기용으로만 활성)
- **배경**: 어두운 딤(약 55%) + 원소 색상의 방사형 그라디언트 + **집중선(speed lines)**: `repeating-conic-gradient`를 천천히 회전·확대. 시작 80ms에 **화이트 플래시**, 보드/HUD **화면 흔들림**(`transform` 애니메이션).
- **캐릭터**: `assets/cutin/{원소}.webp`. 화면 하단 기준 정렬, 높이 약 `min(78vh, 140vw)` 이내. 타이밍(총 1300ms):
  - 0~250ms: 옆(스킬마다 좌/우 번갈아)에서 대각선으로 슬라이드 인 + 약간 오버슈트(`cubic-bezier`), 확대 바운스
  - 250~950ms: 살짝 확대(1.0→1.06)하며 유지, 미세 떨림
  - 950~1300ms: 반대 방향으로 가속하며 슬라이드 아웃 + 페이드
- **말풍선**(HTML/CSS로 그린다. 이미지 안에 글자를 넣지 않는다): 만화 말풍선(흰색, 두꺼운 어두운 외곽선, 꼬리가 캐릭터 입을 향함), 캐릭터 반대편 위쪽에 배치, 약 -4° 기울임. 200ms에 `scale 0→1.2→1` 팝인. 두 줄 텍스트:
  - 윗줄(작게): 외침 대사 / 아랫줄(크게·굵게): **기술 이름**, 원소 색 텍스트 + 흰 외곽선(`-webkit-text-stroke` 또는 `paint-order: stroke`), 글자 그림자.
- **이름표**: 캐릭터 발밑에 작게 `원소 아이콘(보석) + 캐릭터 이름`.
- 모든 애니메이션은 `transform`/`opacity` 중심(GPU), 종료 후 DOM 정리. 이미지 미로드 시 말풍선 텍스트만 표시하는 폴백.

### 4-4. 컷인 직후 공격 이펙트 강화 (게임 규칙·수치는 spec §3 그대로, 연출만 추가)
- **불**: 대상 칸 중심 폭발 — 방사형 불꽃 플래시, 3×3 범위로 퍼지는 충격파 링, 불씨 파티클, 강한 화면 흔들림.
- **물**: 화면을 가로지르는 푸른 파도 스윕(보드 위), 물방울·얼음 조각 파티클, 타이머 바 서리 효과.
- **풀**: 대상 칸에서 상하좌우로 덩굴(초록 선)이 순차로 자라며 지나가는 칸의 보석이 터짐, 나뭇잎 파티클.
- **번개**: 화면 상단에서 대상 보석들로 내리꽂히는 지그재그 번개(SVG polyline 등, 60ms 간격), 번쩍임(깜빡임 플래시), 흔들림.
- **어둠**: 보드 중심에서 보라색 소용돌이/링이 퍼지며 화면 가장자리가 어두워졌다 복귀, 점수판 보라 글로우.
- **빛**: 위에서 내려오는 황금 빛기둥 + 반짝이 파티클, 화이트 플래시, 타이머 바 반짝.
- 제거되는 보석은 기존보다 **크게 터지는 모션**(스케일 업 + 밝기 + 페이드)으로. 파티클 DOM은 기존 한도(동시 최대 약 60개)를 지킨다.

### 4-5. 구현 시 주의
- 컷인 진행 상태 `cutinActive`를 두고: 입력 잠금, 타이머/정지/배율 시계 멈춤, `visibilitychange` 자동 일시정지·메뉴 일시정지와 충돌하지 않게(컷인 중 일시정지되면 컷인도 중단·정리 후 일시정지 처리).
- 시간 종료 직전 컷인 중이어도 종료 화면 전환 순서가 꼬이지 않게 한다.
- 컷인 이미지는 게임 시작 시 미리 로드·`decode()`.
- 건너뛰기/연타 시 효과가 **두 번 실행되지 않게** 한 번만 실행되도록 방어한다.
